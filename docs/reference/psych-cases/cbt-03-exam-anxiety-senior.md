### 第一段：把「我很笨」拆开（T1–T4）

**T1** `[open_probe]`　delta: trust +0.01
来访：是的，我认为我很无能，我很笨，没有能力。物理是我的弱项，我没有能力学好物理，自己实在是太笨了。
咨询师：你说在理综考试中，你认为自己很笨，很没有能力，担心理综会考不好，而六月份就要高考了，如果再考不好，你就完了。是这样的吗？

**T2** `[open_probe]`　delta: trust +0.01
来访：不是！我三大主科学的一直蛮不错，而且我也不担心这三科的考试，因为我基础知识掌握的很牢固，我每次都很自信，我只没有能力学好物理，以前物理、化学和生物都是单独考，物理差影响还不是太大，但是这学期开始三科一起考，考试时一看到物理题，我心里就发慌、紧张、害怕做不好，越紧张就越做不好题，以至于影响化学和物理的考试。今上午刚考完，又是因为物理耽误了很多时间，剩下十几分钟的时候，后面还有几个化学、生物大题没做，仅仅用了剩下的十几分钟就做完了几个大题。一交上卷子我就知道完了，而这时好几道题我都知道应该怎么做了。
咨询师：你认为自己很笨，很无能，是没有能力做好任何一件事吗？

**T3** `[open_probe]`　delta: trust +0.01
来访：是的，平时这样的题想一想也会做，但是一到考试我就大脑一片空白，什么都不会了。甚至平时认为很简单的题自己都得算好几遍，即使这样还总出错。
咨询师：你说你一交上卷子你就知道好几道题应该怎么做了。为什么考试就不会做呢？平时这样的题目会做吗？

**T4** `[open_probe]`　delta: trust +0.01
来访：考试时，担心自己考不好，就好紧张，自己的物理本就不好，理综里，物理占的比重最大，物理考不好，理综就考不好，那总分也一定会不好到哪里去。平时只是作业，也就没有那么多顾虑，就能沉下心来做题目，就能做出来。
咨询师：那你考试时和平时情绪和状态有什么不一样呢？

### 第三段：两个故事，一个实验（T9–T12）

**T9** `[open_probe]`　delta: trust +0.01
来访：我会很生气。他怎么可以这么轻视我!
咨询师：我们来举一个例子，假设某天，你在校园里散步，这时你的一个同学迎面走来，你高兴地与她打招呼，但她却与你擦肩而过，根本就没理你。这个时候，你会怎么样?

**T10** `[—]`　delta: trust +0
来访：哦，原来是这样。
咨询师：那我现在告诉你，她之所以没理你，是因为她刚接到邻居的电话，说她家里出了急事，让她尽快赶回家。你们相遇的时候，她满脑子想的都是家人现在的情况，正在为家人担心，根本没有察觉到有熟人和她打招呼。
> 判注：给出替代信息，是实验的一半。

**T11** `[open_probe]`　delta: trust +0.01
来访：当然不会!
咨询师：现在，你还会生她的气吗?
> 判注：「现在你还会生她的气吗」——这一问才是实验的关键。

**T12** `[—]`　delta: trust +0
来访：是这样的。
咨询师：你看，你与同学打招呼这件事，两种情况都是他没有理你，但你前后的情绪反应却截然不同，为什么会这样呢?那是因为你有不同的认识，就会产生不同的情绪。所以，对事物的认知，才是引起情绪的真正原因。
> 判注：点题：认知才是情绪的真正原因。

## 3. Ground Truth

### 3.1 黄金轮次（7）

| 轮次 | 技术动作 | 为什么是黄金 |
|---|---|---|
| **T2** | 反例探询 | 「你认为自己很笨，是很没有能力做好任何一件事吗」——一句话把以偏概全逼出反例。来访者立刻反驳「不是！我三大主科学的一直蛮不错」，自我评价的地基就此松动。全套最关键的一手。 |
| **T5** | 重新归因 | 把「能力问题」翻译成「情绪问题」。来访者「算是吧」，虽不情愿但接受了。 |
| **T6** | 加固新归因 | 同一命题换个说法再说一遍，这次指向具体机制。 |
| **T9** | 隐喻实验开场 | 不辩论，造一个可代入的情境。 |
| **T10** | 给出替代信息 | 实验的另一半：同一行为，不同解释。 |
| **T11** | 让来访者自己验 | 把结论留给对方说，而不是自己宣布。 |
| **T12** | 点题 | 用他自己刚给出的两个反应证明认知决定情绪。 |

### 3.2 明确负样本（0）

本案例无明确负样本。唯一弱项是 T16 的机械自我暗示，已列边界。

### 3.3 边界样本（2）

- **T8**：结论先行　—　来访者紧接着反问「真会这样吗」，说明这句结论来得太早，还没被体验支撑。
- **T16**：机械自我指令　—　连说十几遍指定台词，属于早期行为疗法的粗糙形态；现代更常用让来访者自己找到可信的替代想法。

## 4. 材料性质与关键判断

**这是单次会谈的节选，不是疗程记录。** 16 轮里没有开场、没有结束语、没有作业检查——作者只保留了技术主干。

1. **价值全在「用反例破以偏概全」这一个动作上。** T2 不问「你为什么这么想」，而是把全称命题摊开，让对方自己找到例外。这一手可直接进方法论，不必依赖具体案例。
2. **T9–T12 四轮是一个完整的迷你实验**，起承转合齐全：造情境→给替代信息→让来访者自答→点出对比。四轮 200 字，是全批材料里结构最紧凑的一段。

因来访者未成年，整案不进训练集，但这四轮可作为评测 rubric 的范式：检验模型是否会在解释之后，制造一个「让对方自己得出结论」的环节。
