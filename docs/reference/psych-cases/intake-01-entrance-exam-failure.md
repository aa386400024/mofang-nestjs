## 3. Ground Truth

### 3.1 黄金轮次（5）

| 轮次 | 技术动作 | 为什么是黄金 |
|---|---|---|
| **T9** | 从观察切入 | 「你看起来情绪很低落，是发生了什么事情的吗？要不要告诉我是怎么一回事」——不问「你有什么困扰」，用观察开场，且把「要不要说」的选择权留给她。 |
| **T10** | 澄清式复述 | 「你的高考没有考好，是没有达到预期的分数啊」——把模糊的「考得很差」变成可确认的事实。 |
| **T11** | 命名打击 | 「高考的失手落榜对你的打击很大，令你觉得很困扰吗」——给出准确的词（失手落榜），再问是否成立。 |
| **T13** | 转向时间线 | 「那你觉得不是试卷记错分数的问题，那你可以讲一下临近高考时的情况吗」——把一个死胡同（分数问题）转成可探索的时间线。 |
| **T15** | 直接问期待 | 「你父母对你的成绩是否要求很高」——不绕，直接问。来访者回答「没提要求，但感觉到期盼」，这句是本案例最有价值的材料。 |

### 3.2 明确负样本（0）

本案例无负样本。前 8 轮框架交代规范（包括先征得同意再介绍原则、登记表允许留白），是可用的初访模板。

### 3.3 边界样本（3）

- **T12**：引导性提问　—　「那么说你觉得是卷子出了问题，是这样吗」——把她还没说清的想法直接命名成「卷子出问题」，虽然后来被否证，但这个提法本身有诱导。
- **T16**：一般化后带引导　—　「父母一般都会有望子成龙的心态」是好的一般化，但紧接「是不是使你觉得有很大的压力」把结论递到了她嘴边。
- **T18**：预设式提问　—　「老师同学对你都寄予厚望的吧」——「寄予厚望」是咨询师塞进去的词，来访者的回答（「关系一直很好，大家都很意外」）其实没有承接这个预设。

## 4. 材料性质与关键判断

**这是一份「流程示范」，技术密度低，但覆盖了初访最容易做错的地方。**

值得学的三点：

1. **T6 先征得同意再介绍原则**——「我想向你介绍心理咨询的基本原则，可以么」。多数模型会直接开始讲设置，这个小动作是尊重。
2. **T4 登记表允许留白**——「你尽量写，不想写的可以不写」。初次接触就给拒绝空间。
3. **T9 从观察切入而非从问题切入**——「你看起来情绪很低落」，比「你有什么问题」温和得多，也更符合初访的实际。

弱点集中在 T12/T16/T18 三次引导性提问：咨询师把词递到来访者嘴边（「卷子出问题」「有很大的压力」「寄予厚望」），其中有两次来访者并没有真的承接。这类提问在初访里很常见，也是模型最容易学坏的句式。

**这份卡的主要用途是「初访流程 checklist」**，而不是技术范本。
