## 4. 材料性质与关键判断

**与「酒」同一套体系：病史采集规范，干预手段已被淘汰。**

前 9 轮的采集值得学，尤其两处：**T3 用对比问句让对方自己承认「偷」**（不贴标签而完成命名），**T6 让来访者完整描述冲动循环**（紧张→心跳→大脑模糊→满足→焦虑），这是性相关障碍评估里最该问、也最容易被跳过的一段。

从 T10 起转向电刺激厌恶疗法。这里有两个层面的问题：

1. **技术层面**：以疼痛打断性兴奋，疗效不可持续，现代已被认知行为治疗、复发预防与药物治疗取代。
2. **伦理层面**：让来访者**亲手挑选**最容易引起冲动的图片作为刺激材料，等于让他参与设计自己的惩罚；全程没有知情同意的记录。

还有一条更值得记录的判断：**这份材料从未处理「偷窃」背后的关系丧失**。初恋被拆散、母亲是唯一依恋对象、姐姐是性冲动的起点——三个线索在 T7 都被采集到了，此后再无下文。治疗只针对行为，没有针对那个「用内衣留住一段关系」的人。这是本卡最大的技术遗憾，也是现代治疗会首先入手的地方。
