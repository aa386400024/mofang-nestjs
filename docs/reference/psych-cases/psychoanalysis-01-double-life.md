### 原生家庭
- **父亲**：大学教授、研究生导师；做事极认真、追求完美、不容瑕疵；要求女儿样样比别的孩子出色；做不到罚跪搓板；不忙时也待在书房
- **母亲**：也是教授，随和、照顾生活起居周到，但**永远站在父亲那一边**；女儿求助时只会说「你一定能做好，你可以的」
- **家庭结构**：「两个书房，一个我学习的地方」，父母之间只聊教学科研——**家被办成了教研室，她像住在教室里的唯一学生**
- **情感缺口**：父母对她的要求与对学生一样；她觉得自己「跟那些学生没什么区别，只是住在同一个屋檐下」

### 三处关键细节
1. **跪搓板**：小时候考不到第一就罚；长大后内化成「做不到就对不起父母」
2. **父母的失望**：不是打骂，是「更加冷淡」——所以她怕的不是惩罚，是被疏远
3. **对母亲的抱怨**：不是没照顾，是「缺那种亲情的交流」；她希望母亲站在她角度，母亲只会说「你可以的」

## 3. Ground Truth

### 3.1 黄金轮次

| 轮次 | 动作 | 为什么是黄金 |
|---|---|---|
| **T33** | 主动给出「好女儿 / 好学生 / 好员工」三重身份的假设 | 来访者**当场笑得很灿烂**——非言语验证了假设；先肯定再解释，把「你为什么这样活」变成她自己认下的事 |
| **T38** | 从酒吧谈话转向「你跟父亲的关系」 | 全场结构转折：从行为描述进入关系史，且转向之前先铺了「你一直注视着我」的观察 |

## 4. 材料性质：这是「示范 + 自注」，不是「被督导的咨询」

**必须说清楚，否则会高估本卡的标注质量。**

| | 双面镜案例一 / 三 / 四 | 本案例 |
|---|---|---|
| 对话来源 | 现场模拟咨询录像转写 | 教材案例（杨凤池、高新义） |
| 谁在点评 | 外部督导（刘丹/李松蔚、曾奇峰、张沛超/申荷永） | **治疗师本人** |
| 点评性质 | 事后判断「这个动作对不对」 | 当场说明「我这个动作用了什么技术」 |
| 可信度 | 高（有第三方反驳与修正） | 中（只有自述，没有反驳） |

**所以本卡的 gold 只收「来访者当场用反应验证过」的轮次**（T33 的笑、T64 的接住、T109 之后的松动），不收「作者自己说这招好」的轮次。作者注释里标为「技术正确」但来访者没有明显回应的（如 T69、T78、T90），一律降为边界。

### 作者的六条技术自述（原注释归纳）

1. **开放式提问 → 具体化 → 释义** 的三段推进：先让她把场景说细（T2–T18），再指出场景的意义（T19）
2. **自由联想与意象**：让她「描绘」酒吧画面（T13）、描绘与父亲亲密的场景（T41）、用花做投射（T92–T99）
3. **一般化**用来卸羞耻（T39、T70）
4. **释义**用来连接行为与需求（T64、T76、T112）
5. **自我表露**只在 T109 用了一次，且是拿自己做对照，不是倾诉自己
6. **收尾**用「改变需要时间」降低她的急（T120）

### 三条本卡自己加的判断（作者没说的）

1. **T33 是全场技术含量最高的一轮**，因为它同时做了三件事：给假设、给肯定、留下验证空间（她笑了）。作者注释只写了「验证假设」。
2. **T102 / T104 的 preaching 不是风格问题，是时机问题**——它们都出现在她刚被理解之后。如果晚五轮、等她自己说出「我想试试别的办法」再说，同样的内容就不构成负样本。
3. **本案例的解释密度明显高于双面镜四例**，这与治疗师取向（经典精神分析）一致，但对模型的示范风险也更高：**模型容易学到「多解释 = 专业」**。因此本卡的 25 轮解释里，只有 8 轮进 gold。

## 6. 待办

1. **T90–T91 的长篇讲授是否该整体降为负样本**，需要一位真人督导判断。现在计边界，是因为来访者确实跟上了（「那我是平衡的，还是说哪部分比例比较大」），但「跟上了」不等于「受益了」。
