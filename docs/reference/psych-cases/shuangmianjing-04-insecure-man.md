## 4. 督导总评

### 4.1 张沛超：精神分析视角的逐句解析

> "整个过程中咨询师说的多了一点，提问式的多了一些，尽量让来访者多一些自然的主动的表达，而不是我们引领他表达。作为咨询师用心去听，听之以心，多一些感受，有感而发。"

### 4.2 申荷永：荣格分析心理学与中国文化视角

> "我并不一定很支持你这种做法……关键不是他的错，不是阿季的错，他即使想'杀掉'校长，是校长的错。"
> "阿季也是被丢掉过的孩子，你就知道抱持对他来说多重要……这个可能是他受委屈背后的更深的一个问题所在。"

### 4.3 张沛超：案例研讨（真实个案第 23 次后，05 案例研讨：去看见，是一种勇敢）

> "你可能要替很多人在问了，这是一个震撼灵魂的疑问——你是谁，为了谁。"

**材料性质：被督导的模拟咨询**——张沛超逐句解析＋申荷永、丛中两份案例研讨，是 11 案里督导密度最高的一案。

**三条关键判断**

1. **T41–T49 是全案技术最难的一段**。咨询师连续三次把「没用」往外推（「有没有可能咨询就是没用的」「咨询师其实没用」），逼出了「我说你不行，你肯定讨厌死我了，你就不给我咨询了」——这句是移情核心，也解释了他为什么每次都想取消预约又照约。

2. **T84 的突破不是解释出来的，是等出来的**。咨询师只是把他反复出现的结论合并成一句「无论你取得什么成绩，最后结论都一样」，他自己说出「我跟我爸很像」。前面八十几轮的铺垫，换来的是这一句自发的材料。

3. **他的「没用」有生死分量**。T54「我爸当年要把我往河里扔」——他的「有用」不是自我价值问题，是活下去的条件。这解释了为什么任何「你其实很好」的安慰都无效，也解释了为什么咨询师 T31/T72 的自我暴露会被他推开。

**张沛超的批评**：''整个过程中咨询师说的多了一点，提问式的多了一些，尽量让来访者多一些自然的主动的表达''——这条批评与 §3.3 里长解释偏多的判断一致。
