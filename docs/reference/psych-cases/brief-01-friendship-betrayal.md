## 3. Ground Truth

### 3.1 黄金轮次（8）

| 轮次 | 技术动作 | 为什么是黄金 |
|---|---|---|
| **T3** | 开放引导 | 「那你能跟我具体说说是什么事情让你感到郁闷呢」——不问「为什么郁闷」，问「什么事」。来访者第一次完整讲出事件。 |
| **T4** | 精准复述＋命名情绪 | 把「不理不睬」与「和别人走得近」两件事分开复述，再命名「伤心、愤怒」。复述准确，命名不外推。 |
| **T5** | 共情后立刻推进 | 「我很能理解你现在的心情」只一句，紧接着追问矛盾——共情不铺陈，保持会谈节奏。 |
| **T7** | 把用词递回 | 「报复?你认为她这是在报复你吗」——不反驳也不认同，只把她的判断原样递回。来访者随后自己加固了这个判断，但至少它被审视过一次。 |
| **T8** | 给替代解释留门 | 「那她不能陪你，是不是真的因为有其他的事情要做呢」——不否定她的归因，只提出另一种可能。她沉默 10 秒，这是全场唯一一次松动。 |
| **T10** | 转向旧账 | 「那你把那件事情具体跟我说说好吗」——把「闹过矛盾」这件被轻轻带过的事重新展开，问出共同暗恋对象这段历史。 |
| **T11** | 点出三角 | 「那你现在的男朋友是你们共同喜欢的那个男生吗」——一句话把关系结构摆到桌面上。 |
| **T12** | 回到归因 | 「那你认为她不理你的原因是什么呢」——在三角关系摊开之后再问归因，此时的答案已经和第一次不同（从「她报复我」变成「讨厌的同学挑拨」）。 |

## 4. 材料性质与关键判断

**这是一份「低技术、高结构」的材料。**

13 轮里没有一个理论名词、没有一次解释、没有作业，只有问句和两次复述。但它在结构上做对了一件很难的事：**把一个人的抱怨，还原成一张关系图**。

- 第一层：好友冷落我（她的叙述）
- 第二层：因为我交了男朋友、冷落了她（她自己说出口，但立刻转回「她在报复我」）
- 第三层：我们曾经同时喜欢一个男生，而现在的男友就是他（T11 点出）
- 第四层：还有一个「讨厌的同学」在中间挑拨（她的最终归因）

咨询师没有替她选任何一个版本，只是逐层把事实摆出来。**这正是「不解释也能工作」的样本**——对训练一个总想给解释的模型来说，这类反例比黄金解释更有价值。

缺的是收尾：三角关系刚摊开就时间到了，没有做任何小结或作业。作为单次会谈它不完整，作为「澄清技术」的样本它很干净。
