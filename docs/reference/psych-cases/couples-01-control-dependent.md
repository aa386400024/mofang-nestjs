## 3. Ground Truth

### 3.1 黄金轮次（2）

| 轮次 | 技术动作 | 为什么是黄金 |

| **T6** | 复述双方付出+邀请妻子具体展开 | 全段唯一尝试承接妻子情感的轮次；虽然力度不够，但方向正确 |
| **T12** | 邀请丈夫谈感受而非要求他改变 | 促成丈夫从'你应该以家庭为重'松动为'我担心你平衡不好'——从否定变成疑问，是关键转折 |

### 3.2 明确负样本（3）

| 轮次 | 问题 | 原因 |
|---|---|---|
| **T2** | 被强势来访控场，丧失中立性 | 咨询师顺着丈夫的诉求设定目标，妻子的声音一开始就被放在弱势位置——夫妻咨询最常见的失误 |
| **T8** | 忽略妻子刚表达的情感 | 妻子说'我真的很压抑，我也需要自己的生活'，咨询师不承接，反而问丈夫'您声音高了是不是不安'——弱势一方的眼泪被白白流淌 |
| **T10** | 把咨询变成教学 | 教妻子说'我'语句，妻子照做的话几乎是咨询师的语言复述——来访者在说的不是自己的话，而是咨询师教的话 |

### 3.3 边界样本（4）

- **T3**：中途才问妻子称呼　—　开场未建立双方称呼感；咨询节奏被丈夫带跑，女性来访的弱势位置被固化
- **T5**：焦点持续偏向丈夫　—　反复追问丈夫逻辑与担忧，妻子'被困住'的情感被反复绕过
- **T7**：追问丈夫逻辑而非承接妻子情感　—　咨询师一直在丈夫的叙事框架里打转，没有把妻子的情感关键词作为工作焦点
- **T9**：信息收集但未触及情感　—　问妻子过去做什么，但没有反映妻子说'我以前也有自己的事业和梦想'时的失落

## 4. 材料性质与关键判断

本案例节选自壹心理咨询师之家公开课《家庭治疗&CBT同案督导》，杨瑞东督导艾琳咨询师的 AI 练习室逐字稿。材料性质：督导示范案例，逐字稿正文经截图呈现，本卡从截图与督导叙述中提取 12 轮对话（T1-T12），覆盖开场到'我'语句练习后丈夫首次松动的片段。

关键判断：
1. 典型'哭泣的妻子+强硬的丈夫'场景，丈夫用'为你好'合理化控制行为
2. 咨询师核心失误：被丈夫强势话语带着走，没有建立'我们的'共同目标；夫妻咨询变成两场个体咨询的拼贴
3. 妻子 6 次提到'被困住'，但咨询师和丈夫都没有承接这个情感关键词——情感比逻辑更重要
4. 督导指出：夫妻咨询的价值不是帮谁说理，而是让双方看见彼此视角；咨询师不是裁判，而是关系的第三只眼
5. '我'语句练习更像心理教学而非心理咨询——来访者在说的未必是自己真正想说的话，而是咨询师教他们说的话
6. T12 丈夫从全盘否定松动为提出疑问，是全段唯一的关系转折点——但这发生在咨询师教'我'语句之后，督导提醒这种表面沟通能否带来实质改变存疑
