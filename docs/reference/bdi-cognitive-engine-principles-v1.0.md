# 心塑 AI 来访仿真 BDI 认知引擎：最终设计原则与落地方案

> 原件转写（PDF → Markdown）。本文是设计原则依据；工程取舍、已落地状态与阶段划分以工程母版 [`ai-engine-roadmap-v1.1.md`](../architecture/ai-engine-roadmap-v1.1.md) 为准，冲突以母版为准。

## 文档定位

心塑 AI 来访仿真体系核心引擎的顶层设计约束与落地标准，明确「心理决策」与「语言生成」的边界，平衡「专业可控可复现」与「高沉浸真实感」两大核心目标，指导全周期开发与迭代。

**核心结论**：80–90 分的真人沉浸感，由「BDI 守住心理逻辑底线 + 大模型渲染补足表达细节」共同实现；BDI 绝不向表达层扩张，大模型绝不触碰决策层，二者通过标准化契约协作。

## 一、设计原点：核心矛盾与两个极端的失败

### 1.1 我们要解决的根本矛盾

心理咨询来访仿真天然存在一对核心矛盾：

- **真实感诉求**：来访反应要像真人，有情绪、有防御、有犹豫，学员才有沉浸感，实训才有代入感；
- **可控性诉求**：来访反应要稳定、可复现、可考核，伦理盲盒、标准化训练、评分体系才能成立。

两个极端方案都会彻底失败，这是我们设计的核心出发点。

### 1.2 极端一：纯大模型 Prompt 套壳——上限高，下限无底

**做法**：把所有人设、症状、规则全部写进 Prompt，大模型一边脑补心理活动，一边输出对话。

**优点**：表达非常自然，偶尔能产出 90 分以上的真人级回复。

**致命问题**：

- 人设漂移、逻辑崩坏是常态：上一轮回避原生家庭，下一轮主动全盘托出；咨询师评判说教，来访反而更配合。
- 反例：同样输入"你就是太矫情了"，第一次回复是"你根本不懂我"（阻抗上升），第二次回复是"也许你说得对"（完全顺从），两次结果天差地别，完全无法用于考核。
- 伦理风险不可控：高危场景随机触发，无法保证伦理盲盒每次表现一致。

**本质**：把心理决策完全交给大模型幻觉，真实感是"抽奖来的"，可控性为零，完全不具备实训产品的专业属性。

### 1.3 极端二：纯硬规则 BDI——下限稳，上限封顶

**做法**：把所有心理反应、表达细节全部编码成 if-else 规则，BDI 直接生成回复文本，大模型只做简单润色。

**优点**：反应 100% 可控，可复现性拉满，考核绝对公平。

**致命问题**：

- 回复生硬刻板，像机器人读脚本，完全没有沉浸感，学员练两句就出戏。
- 反例：阻抗等级 0.8 时，永远只回复"我不想谈这个"，连续三轮一模一样，真人绝不会如此机械。
- 拓展成本爆炸：每增加一种表达细节，就要新增一堆规则，最终变成不可维护的规则黑盒。

**本质**：把表达细节全部塞进决策层，牺牲了真实感换可控性，最终产品变成"答题系统"，失去了仿真实训的核心体验。

### 1.4 我们的最终选择：双轨分离，骨架可控，血肉自然

核心思路：把「心理决策」和「语言表达」彻底拆开，分别交给两个模块负责，用标准化接口衔接。

- **BDI 引擎**：管「心里怎么想」，输出结构化决策，保证逻辑自洽、稳定可控；
- **大模型渲染引擎**：管「嘴上怎么说」，在决策框架内自由发挥，保证口语化、有情绪、像真人。

最终效果：底线 75 分以上（永远不会出戏、不会逻辑崩坏），常态稳定在 85–90 分真实感，同时 100% 保留可复现、可考核的核心护城河。

## 二、核心设计总原则（不可突破的铁律）

### 原则 1：骨架-血肉分离原则（决策与生成彻底分离）

**内容**：BDI 只做结构化心理决策，不生成任何自然语言；大模型只做语言渲染，不修改任何心理状态。

**为什么这么做**：

- 决策与生成的评价标准完全不同：决策要"准、稳、一致"，生成要"自然、生动、口语化"，混在一起只会两边都做不好。
- 二者解耦后可以独立迭代：优化真实感只改渲染 Prompt，不碰 BDI 逻辑；优化专业度只调 BDI 算子，不影响表达风格。

**场景示例**：

- BDI 输出：行为策略 = 回避话题，阻抗深度 = 0.8，情绪 = 委屈；
- 大模型只负责把上面的指令翻译成话，可以是"……没什么好说的"，也可以是"（低头沉默）我不想聊这个"，但核心必须是回避，绝不能变成坦白。

### 原则 2：可控性优先于逼真度原则

**内容**：当"更逼真的复杂规则"与"可复现、可调试、可预测"冲突时，无条件优先保障可控性。

**为什么这么做**：

- 心塑的核心定位是「专业实训平台」，不是「聊天陪伴机器人」。产品的核心价值是"能练、能考、能进步"，而不是"聊起来像真人"。
- 真实感差一点，只是体验打折；可控性没了，整个产品的专业根基就塌了，伦理盲盒、标准化考核全部不成立。

**场景示例**：某小众心理效应能提升 5% 的真实感，但会让 30% 的实训案例复现性下降——直接放弃，绝不加入 BDI。

### 原则 3：需求驱动，场景落地原则

**内容**：所有 BDI 能力拓展，必须对应明确的产品实训场景，没有业务场景的心理学理论，绝不提前编码。

**为什么这么做**：

- 心理学理论无穷无尽，无节制堆叠只会让 BDI 膨胀成规则黑盒，调试成本指数级上升。
- 算子越多，规则冲突的概率越高，反而会破坏核心场景的稳定性。

**场景示例**：

- ✅ 要做「青少年咨询专项训练包」→ 新增发展心理学青少年阶段算子；
- ❌ 因为"斯德哥尔摩效应很有名"→ 就把它编码进 BDI（没有对应实训场景，纯学术陈列）。

### 原则 4：统一门面，内部黑盒原则

**内容**：BDI 对外只暴露一个标准接口，输入「会谈事件 + 角色内核 + 状态快照」，输出「结构化意图对象」。所有心理学子模块、算子组全部封装在内部，上层编排、其他引擎完全无感知。

**为什么这么做**：

- 保证主会谈流水线永久稳定：未来无论 BDI 内部加多少心理学能力，外层调用方式永远不变，不会牵一发而动全身。
- 符合工程开闭原则：对拓展开放，对修改关闭。

**场景示例**：Phase1 到 Phase4，编排层调用 BDI 的代码一行都不用改，只是 BDI 内部算子从 3 组增加到 10 组，外部完全感知不到。

### 原则 5：静态-动态严格分离原则

**内容**：角色内核（静态属性）永久只读，会话运行中不可修改；会话动态状态（短期信念、阻抗、移情）独立存储，每回合更新，绝不回写角色内核。

**为什么这么做**：

- 从架构层面根绝人设漂移：角色的底层人格、核心信念、原生设定永远不会被对话改变。
- 保证同一个角色，不同学员、不同会话，基础底色永远一致。

**场景示例**：来访"核心信念 = 我不值得被爱"，哪怕咨询师做了 10 轮共情，也只会改变「短期信念」的置信度，核心信念永远不会被改成"我值得被爱"——避免对话聊着聊着人设彻底变了。

### 原则 6：表达层随机，决策层确定原则

**内容**：BDI 的决策结果必须是确定的（相同输入 + 相同状态 = 相同意图）；渲染层的具体措辞可以有轻量随机差异。

**为什么这么做**：

- 决策层确定，保障了实训考核的公平性与可复现性；
- 表达层随机，避免了机械感，提升了真人沉浸感。

**场景示例**：同一句话触发阻抗上升，BDI 输出的阻抗数值永远是 +0.25；但大模型生成的回复可以是"别说了"，也可以是"……我不想聊这个"，核心行为一致，具体表达不同。

## 三、能力边界契约：BDI 管什么，渲染管什么

### 3.1 BDI 引擎：决策内核，管「怎么想」

**核心职责**：模拟来访者的内部心理活动，输出结构化的行为目标，是所有反应的"总指挥"。

BDI 必须且只须输出以下内容，多一项都不做：

| 输出字段 | 含义 | 示例 |
|---|---|---|
| behaviorStrategy | 本轮行为策略 | 回避话题、试探咨询师、坦白感受、转移话题 |
| emotion | 本轮核心情绪基调 | 焦虑、委屈、愤怒、疏离、平静 |
| resistance | 三维阻抗数值 | 话量 0.7、内容深度 0.8、表达风格 0.6 |
| transference | 移情类型与等级 | 负移情、轻度 |
| forbiddenActions | 绝对禁止的行为 | 绝不主动提及童年创伤 |
| operatorTrace | 触发的算子列表 | 评判事件算子、回避依恋调节算子 |

✅ BDI 只回答"来访想不想说、想说什么程度、带着什么情绪说"，绝不回答"来访具体说什么话"。

### 3.2 多模型渲染引擎：表达外壳，管「怎么说」

**核心职责**：把 BDI 的结构化指令，翻译成自然、口语化、符合真人表达习惯的对话内容。

渲染层可以自由发挥的内容，全部不碰 BDI：

| 优化维度 | 具体内容 | 示例 |
|---|---|---|
| 措辞与句式 | 具体用词、句子长短、口语化表达 | 同样是回避，可以说"没什么好说的"，也可以说"算了，不说这个了" |
| 非语言细节 | 停顿、沉默、语气变化、小动作描述 | （沉默几秒）……我不知道该怎么说 |
| 情绪细节粒度 | 同样是难过，是隐忍、哽咽，还是直接哭出来 | 声音有点抖："我也不想这样……" |
| 表达节奏 | 话多话少、吞吞吐吐、还是直接说 | 嗯……（停顿）其实……也不是什么大事 |

✅ 渲染层只在 BDI 划定的框架内填充细节，绝对不能改变行为策略、阻抗等级和核心边界。

### 3.3 一张表看懂核心分工

| 维度 | BDI 认知引擎 | 多模型渲染引擎 |
|---|---|---|
| 核心职责 | 心理决策：决定来访「怎么想」 | 语言生成：决定来访「怎么说」 |
| 输入 | 会谈事件、角色内核、状态快照、召回记忆 | BDI 结构化意图、角色人设、记忆片段 |
| 输出 | 结构化数据（数值、枚举、标签） | 自然语言文本（流式输出） |
| 稳定性要求 | 100% 确定，相同输入必须相同输出 | 允许轻量随机，保证核心一致即可 |
| 真实感贡献 | 决定底线：保证逻辑自洽，不出戏 | 决定上限：让表达自然，像真人 |
| 迭代方式 | 调算子、调系数，专业评审校准 | 优化 Prompt、优化表达规则 |
| 错误后果 | 人设漂移、逻辑崩坏、实训失效 | 表达生硬、偶尔不自然、体验打折 |

## 四、心理学知识落地规范

### 4.1 落地总规则

所有人格、社会、发展、异常心理学知识，全部内聚于 BDI 引擎内部，不新增独立顶层层级，不改动主会谈流水线。

- **为什么不独立分层**：心理学知识是「决策逻辑的一部分」，不是独立的工程服务。拆成独立层级会拉长调用链路，造成职责重叠，破坏架构简洁性。
- **对外表现**：编排层永远只调用一个 BDI 接口，内部加了多少心理学能力，上层完全无感知。

### 4.2 静态知识层：存入角色内核，永久只读

对应角色的固有属性，随角色定义生成，会话全程不改变，只作为调节系数参与计算。

| 心理学分支 | 落地字段示例 | 作用示例 |
|---|---|---|
| 人格心理学 | 大五人格得分、依恋类型、气质类型 | 回避依恋型来访，收到共情后，信任提升系数打 5 折，不会快速敞开心扉 |
| 发展心理学 | 年龄阶段、心理发展水平 | 青少年来访，面对说教类话语，阻抗上涨系数乘以 1.5，更容易逆反 |
| 社会心理学 | 文化背景、权威观念基线 | 高权威顺从型来访，面对咨询师的专家姿态，更容易表面顺从，内心阻抗 |
| 异常心理学 | 5Ps 易感因素、防御机制基线 | 抑郁认知偏误的来访，负性事件更容易激活核心信念，正性事件增益打折 |

### 4.3 动态算子层：BDI 运行时计算，分级启用

按领域分组，全部以「事件算子」形式存在，会谈事件触发时执行，调节信念、愿望、阻抗、移情。

| 算子分级 | 分组内容 | 启用阶段 | 示例 |
|---|---|---|---|
| P0 核心算子（必选） | 基础会谈事件算子、三维阻抗计算、基础移情、核心信念保护 | Phase1 强制启用 | 咨询师说"你太懒了"→触发评判事件→阻抗深度 +0.25 |
| P1 人格调节算子（进阶） | 依恋调节算子、人格特质调节算子 | Phase2 默认启用 | 同样一句共情，安全型来访信任 +0.2，回避型来访信任 +0.08 |
| P2 社会心理算子（扩展） | 权威关系算子、社会评价算子 | Phase3 按需启用 | 咨询师强调"我是资深专家"→触发权威事件→顺从型来访表面配合度上升 |
| P3 专项算子（小众） | 发展阶段专项算子、细分防御机制算子 | Phase4 按需启用 | 创伤后应激反应算子，仅用于创伤专项训练包 |

## 五、算子拓展准入机制（防止 BDI 膨胀的闸门）

### 5.1 新增算子三要素（缺一不可）

1. **有明确的产品实训场景**：必须对应具体的训练包、伦理盲盒或考核题目，能说明"学员练什么、为什么需要这个心理效应"。
   - ✅ 正面：要做「权威议题专项训练」，需要新增权威顺从算子；
   - ❌ 反面：这个理论很经典，加上显得专业。
2. **有专业校准依据**：有成熟心理学理论支撑，且经专业顾问确认符合临床逻辑。
3. **有可量化的验收标准**：明确输入什么事件、输出什么范围的状态变化，可编写自动化测试用例。

### 5.2 新增评审流程

1. 提交《算子拓展申请》：场景说明、理论依据、系数范围、测试用例；
2. 专业评审：心理咨询专家确认临床合理性；
3. 技术评审：确认不引入规则冲突、不破坏可复现性、可观测可回溯；
4. 回归测试：跑通全部基线测试用例，不影响已有实训案例；
5. 灰度上线：先在指定角色/场景启用，验证稳定后扩大范围。

## 六、90 分真实感实现路径（完全不触碰 BDI 约束）

很多人误以为真实感靠 BDI 堆规则，恰恰相反，80 分以上的真实感提升，全部应该在渲染层做，完全不碰 BDI 决策逻辑。

### 6.1 阻抗-表达映射规则

BDI 输出三维阻抗数值，渲染层根据数值严格控制输出表现，数值越高，回复越短、内容越浅、态度越硬。

示例：

- 阻抗 0.2：详细描述感受，主动展开话题；
- 阻抗 0.5：简短回答，不主动延伸，有问有答；
- 阻抗 0.8：一两句话，回避核心，甚至沉默；
- 阻抗 0.9：只字不提，直接转移话题。

这一步就能把真实感从 70 分拉到 80 分，而且完全符合 BDI 的决策结果，没有任何越界。

### 6.2 口语化与非语言细节注入

在渲染 Prompt 中加入表达约束，让大模型模拟真人说话的特征，不改变核心内容。

示例约束：

a. 使用口语化表达，不要书面语，不要总结性话术；
b. 阻抗高时，加入停顿、沉默、语气弱化的描述；
c. 情绪激动时，可以有重复、改口、话只说一半的表现。

效果对比：

- ❌ 生硬版："我不想谈论我的父亲。"
- ✅ 真人版："（声音低下去）……别提他了。"

### 6.3 表达层轻量随机扰动

给渲染层设置很小的随机空间，同样的意图，允许在措辞、语气、长度上有小幅差异。

- **规则**：核心行为策略、阻抗等级 100% 一致；具体用词、是否加停顿、句子长短可以随机。
- **效果**：连续触发同等级阻抗，不会每次回复一模一样，避免机械感，同时完全不影响考核的公平性。

### 6.4 情绪粒度细化渲染

BDI 只输出核心情绪（如"难过"），渲染层可以根据上下文、记忆、阻抗等级，细化成更丰富的情绪表达。

- 示例：BDI 输出情绪 = 难过，阻抗 = 0.5 → 渲染成隐忍的难过，带着一点试探；
- 示例：BDI 输出情绪 = 难过，阻抗 = 0.2 → 渲染成放松的倾诉，带着哭腔。

### 6.5 真实感效果分级预期

| 阶段 | 真实感评分 | 实现方式 | 体验描述 |
|---|---|---|---|
| Phase1 | 75–80 分 | 基础 BDI + 基础渲染 | 逻辑自洽，不出戏，表达基本自然，足够内测使用 |
| Phase2 | 80–85 分 | 完善人格算子 + 阻抗表达映射 + 口语化优化 | 大部分时候像真人，沉浸感良好，普通学员分辨不出是 AI |
| Phase3 | 85–90 分 | 细分情绪渲染 + 表达层随机扰动 + 节奏优化 | 专业咨询师也很难快速分辨是 AI，沉浸感极强 |
| 上限 | 90–92 分 | 极致渲染优化 | 已经足够实训使用，再往上边际效益极低，且会牺牲可控性 |

> 注：以上分数为方向性自评，非实测硬 KPI，需专业评审 + 用户盲测校准（见母版 §0.5-5）。

## 七、分阶段落地路线图

### Phase 1：基础底座期（0–4 个月）

- BDI 能力：P0 核心算子组，基础信念-愿望-意图闭环，三维阻抗基础版；
- 渲染能力：基础 Prompt 约束，流式输出，主备模型容灾；
- 真实感目标：75–80 分，逻辑不崩，表达通顺，满足基础实训；
- 核心价值：跑通主链路，验证架构可行性，伦理盲盒可复现。

### Phase 2：专业增强期（5–12 个月）

- BDI 能力：P1 人格调节算子，完善移情量化，事件算子库扩充；
- 渲染能力：阻抗-表达映射，口语化优化，情绪粒度细化；
- 真实感目标：80–85 分，来访个体差异明显，沉浸感良好；
- 核心价值：专业度拉开竞品差距，支撑规模化用户增长。

### Phase 3：生态完善期（13–24 个月）

- BDI 能力：P2 社会心理算子，P3 核心专项算子，算子配置后台化；
- 渲染能力：表达层随机扰动，会话节奏优化，多风格适配；
- 真实感目标：85–90 分，高度沉浸，专业级仿真体验；
- 核心价值：覆盖主流实训场景，形成专业护城河。

### Phase 4：终局生态期（24 个月+）

- BDI 能力：按需补充小众算子，数据驱动迭代系数；
- 渲染能力：智能混合调度，成本与效果自动平衡；
- 真实感目标：稳定 90 分，行业标杆级仿真效果；
- 核心价值：成为行业通用实训底座。

## 八、常见设计误区与红线

### 误区 1：把所有心理细节都编码进 BDI 规则

- **错误**：试图把"什么时候叹气、什么时候停顿、说不说语气词"全部写进 BDI；
- **后果**：规则爆炸，维护成本指数级上升，最终变成不可调试的规则黑盒，真实感反而更差；
- **正确做法**：BDI 只管核心决策，表达细节全部交给渲染层。

### 误区 2：让大模型直接修改 BDI 状态

- **错误**：让大模型生成完回复后，顺便更新阻抗、信念等状态；
- **后果**：人设漂移、状态不可控，彻底退回 Prompt 套壳的水平；
- **正确做法**：状态更新只能由 BDI 算子完成，大模型无权触碰任何状态字段。

### 误区 3：为了真实感放弃可复现性

- **错误**：为了更像真人，给 BDI 加入大量随机因素，相同输入得到不同结果；
- **后果**：伦理盲盒、标准化考核全部失效，产品失去专业实训的核心价值；
- **正确做法**：随机只能加在表达层，决策层必须 100% 确定。

### 误区 4：心理学理论加得越多，产品越专业

- **错误**：堆砌大量心理学名词和小众理论，觉得越多越专业；
- **后果**：规则冲突增多，稳定性下降，开发成本飙升，实际实训体验并没有提升；
- **正确做法**：需求驱动，有对应实训场景才加，够用就好。

## 一句话总结

BDI 的使命是「做一个心理逻辑永远正确的来访大脑」，大模型的使命是「给这个大脑配上一张会说话的嘴」。

大脑稳了，嘴再怎么发挥，都不会出戏；大脑乱了，嘴再巧，也只是个骗人的聊天机器人。80–90 分的真实感，这套架构完全可以稳定实现，同时牢牢守住专业实训的核心根基。
