①利尿剂的应用: A．所有心力衰竭病人，有或曾经有过液体
潴留者，均应使用利尿剂。B．利尿剂必须最早应用，襻利尿剂
( 速尿) 应作为首选，其他按照医生要求。C．利尿剂通常从小剂
量开始( 速尿20mg，1 ～2 次/日，氢氯噻嗪25mg 1 ～2 次/日，逐渐
加量。
②血管紧张素转换酶抑制剂( ACEI) 的应用: A．所有慢性心
衰患者必须应用ACEI，而且需要终身使用，除非有禁忌证或不能
耐受。B．从很小剂量开始( 卡托普利6．25 ～12．5mg，2 次/日或
依那普利2．5mg，2 次/日) ，逐渐递增，推荐用量为中等剂量或靶
剂量; 一旦调整到合适剂量，应终身维持使用。C．有低血压史、
糖尿病、氮质血症以及服用螺内酯者，递增速度宜慢; D．目前有
或以往有液体潴留的患者，ACEI 必须与利尿剂合用。E．副作用:
低血压、肾功能一过性恶化、高血钾及干咳。F．禁忌证: 喉头水
肿、无尿性肾功能衰竭、妊娠妇女。
③β 受体阻滞剂的应用。A．适应证: 所有慢性心衰、无症状
性心衰的患者均必须应用β 受体阻滞剂，而且需终身使用; 除非
有禁忌证或不能耐受。重度心衰需待病情稳定、已无液体潴留并
体重恒定后，在严密监护下应用。B．起始剂量: 必须从极低剂量
开始，如: 美托洛尔6．25mg，2 次/日，每1 ～2 周剂量逐渐缓慢递
增。C．目标剂量的确定: 心率是公认的β 受体有效阻滞的指标。
清晨静息心率55 ～60bpm 为达到目标剂量或最大耐受量，不以
患者的治疗反应来确定目标剂量。D．起始治疗的时机判定: 治
疗前患者无明显液体潴留，体重恒定( 干体重) ，利尿剂已维持在
最合适剂量。E．在应用利尿剂和ACEI 的基础上，及早加用β 受
体阻滞剂，并根据临床情况，分别调整各自的剂量。F．禁忌证: a．
支气管痉挛性疾病; b．严重心动过缓、高度及三度房室传导阻滞
( 除已安置起搏器) 者均不能应用; c．心衰患者有明显液体潴留，
应先利尿，达到干体重后再开始应用。
④洋地黄类药物: 可明显改善症状，但不能纠正心衰的病理
生理变化，不能改善长期预后。A．适应证: a．在应用ACEI( 或
AＲB) 、受体阻滞剂和利尿剂基础上，仍持续有症状的心衰患者。
b．重症患者可将地高辛与ACEI( 或AＲB) 、β 受体阻滞剂和利尿
剂同时应用。c．伴有快速心室率的房颤患者。B．洋地黄药物的
选择: a．地高辛: 目前采用维持量法，每日1 次，0．125mg。对70
岁以上或肾功能不良的患者减量。适用于中度心力衰竭维持治
疗。b．西地兰: 0．2 ～0．4mg 稀释后缓慢静脉注射，24 小时总量0．
8 ～1．2mg。适用于急性心力衰竭或慢性心衰加重时，特别适用
于心衰伴快速心房颤动。C．洋地黄药物应用注意事项: a．洋地黄
药物没有明显降低心衰患者死亡率的作用。因而不主张早期应
用，亦不推荐应用于轻度心衰患者。b．急性心衰并非地高辛的应
用指征，除非合并快速室率的房颤。c．急性心肌梗死后患者，应
慎用或不用地高辛，尤其在梗死后24 小时内。e．二度或高度房
室传导阻滞者禁用。f．肺心病导致右心衰，常伴有低氧血症，应
慎用。
一例性别认同障碍导致的抑郁心理案例
温亮宇
( 广东文艺职业学院
511400 )
【摘要】来访者因性别认同障碍导致轻度抑郁情绪。咨询过程中，主要使用了合理情绪疗法。经多次咨询后，来访者情绪状态有所改善，学习
和生活基本恢复正常。
【关键词】性别认同障碍; 抑郁; 心理
1．一般资料: 来访者王某，男，20 岁，汉族，某艺术学院大二学
生，流行音乐专业。平时梳妆打扮、待人接物喜欢以女性自居，入
学前曾做过整容手术去掉胡须。因专业形象突出( 媒体常指伪
娘) ，经常会有商业演出。
2．个人陈述: " 我父母在我很小的时候就离婚了，我从小就
跟妈妈和姐姐生活在一起" ; " 从小的时候我就喜欢跟女孩子在
一起玩，喜欢跟她们谈天聊心事。大概初中开始我就发现自己还
是最喜欢穿女孩子的衣服，喜欢粉红色，喜欢隔壁班的男生。跟
班上的同学交往的也很开心，大家都很容纳关心我。但有一天我
在发现外系的女孩子在议论我上电视节目的表现，取笑我的性取
向。我当时整个人都呆住了。从那天晚上开始，我就一直睡不着
觉，心情很糟，无心做事，很纠结，很痛苦。其实我也知道自己选
的是一条多么坎坷的路，也会继续坚持走下去。虽然已有这方面
的心理准备，但听到别人哪怕是不认识的人在背后嘲笑还是会很
难过" 。" 我是喜欢男生，但不是作为一个男生去喜欢，而是以一
个女孩的心态在喜欢。我不是同性恋，我不想对方也是同性恋。
可是好难。"
3．观察和收集到的其他资料: 来访者首次来访时衣着整齐，
略施淡妆; 在谈话过程中声音很小，面带愁容，说话时偶尔停顿，
很憔悴，常整理自己的头发。
4．心理测试结果: ①SCL －90 测试各因子分如下: 躯体化1．
5，强迫症状1．8，人际敏感1．9，抑郁2．1，焦虑2．4，敌对1．4，恐
怖1．8，偏执1．4，精神病性1．5，其他1．6; 总分156; 阳性项目数
44 个，抑郁、焦虑因子分数明显高于常模。②抑郁自评量表
( SDS) : 粗分46 分，标准分57 分，提示有轻度抑郁。③焦虑自评
量表( SAS) : 粗分43 分，标准分53 分，提示有轻度焦虑。
5．诊断: 对该来访者诊断为一般心理问题，抑郁情绪。
6．病因分析
( 1) 社会原因: 来访者在中学就已经开始易装，有一定的心
理承受能力，但亲耳听到别人在背后对他的性别取向进行议论情
绪还是会产生抑郁情绪，对生活产生较大影响。
( 2) 认知原因: 来访者认为在这个社会上还有很多像他这样
子的人，他们不是人们所想的那样子，他们也有他们的自由，追求
自我的权利，希望大家不要觉得很惊讶。
( 3) 防御机制: 来访者面对被别人背后议论的挫折，主要采
取了压抑这种逃避性防卫机制，担心自尊受挫。

7．咨询目标与咨询方案
( 1) 具体目标: 帮助来访者接受因性别转换遭到别人议论的
事实，改善不良情绪，学会处理感情问题，使其心理测验结果恢复
正常水平; 改变该来访者的饮食和睡眠状况。
( 2) 咨询原理与具体的咨询方法: 本案例来访者的心理问题
表现在受到被别人背后议论的挫折后，出现了痛苦、抑郁、焦虑的
情绪，实际上，这与来访者本身对事情的不合理认识和评价也有
关系，比如，来访者可能存在: " 我就是个平常人，别人为什么不
能像对平常人那样对我" 等一些" 绝对化要求" ，对生活事件" 过
分概括" 和对生活挫折" 反应过分强烈" ，导致了自我挫败感。因
此，运用合理情绪疗法，帮助来访者以合理的思维方式代替不合
理的思维方式，以合理的信念代替不合理的信念，帮助来访者减
少或消除情绪困扰及行为障碍。
8．咨询过程
( 1) 第一次咨询: 咨询过程中告知了相应的咨询理论的知
识，摄入性谈话了解了来访者的基本情况，做了相关的心理测验，
更全面地掌握了来访者的状况，对测验结果做了简单分析，并初
步确定了咨询目标。
( 2) 第二次咨询: ①要求来访者列出自己的许多不合理信
念，但他涉及此次情绪问题的不合理信念并没有完全列出。②要
求来访者进一步详谈他平日的一些情况，列举出他的好朋友有哪
些、她平日和朋友们的一些喜好、选择朋友的标准，以及自己对于
选择男朋友的标准，打破来访者心目中认为自己就是个平常人，
别人一定要像对平常人那样对待自己的观念，从深层次上挖掘自
己的不合理信念。③布置了咨询作业，要求来访者反思列出的不
合理信念，以便帮助来访者把注意转移到关注自己的不合理信念
上来，并领悟自己的问题与不合理信念的关系。这里有一段咨询
对话的摘录:
咨询师: 你为什么会这么难过呢?
来访者: 我只是一个普通人，为什么不认识我的人会那样认
为我。
咨询师: 你觉得你只是一个普通人，但不了解你的人却在背
后议论你的性别取向，是这样吗?
来访者: 是的，在这个社会上还有很多像我这样子的人，我们
也不是别人所想的那样子，我们也有我们的自由，追求自我的权
利，我就是个平常人，也希望大家像对平常人那样对我。
咨询师: 如果你认识那些人，你认为他们还会在背后这样议
论你吗?
来访者: 是我的朋友就不会在背后这样议论我。如果是认识
的人在背后说我我就会努力让他们了解我是个什么样子的人。
咨询师: 既然你已经有答案了，那为什么还要难过呢?
来访者: 我就是受不了别人在背后这样说我。
咨询师: 别人议论你是因为他们想了解你，既然这样，何不找
个时间大家相互了解一下，以你的性格，我觉得说不定还会变成
好朋友呢。
来访者: 我想有机会的话我也会让他们好好了解我，知道我
是一个什么样的人。
( 3) 第三次咨询: 本次咨询是最重要的一个阶段，在认识到
不合理信念的基础上，帮助她修正不合理信念，建立积极合理信
念，并最终减轻情绪困扰。
经与来访者进行商讨与辩论，得出如下建设性信念: ①别人
背后谈论我，是因为不了解我。②我应该多参加学校各类活动，
让大家懂我，接受我。③我应该把这件事作为一个警示，以后还
碰到这些我会坦然接受，积极面对。
( 4) 第四次咨询: 本次咨询目的在于结束咨询过程巩固咨询
效果，运用了合理情绪疗法、心理测验法。①咨询作业的反馈: 来
访者与背后议论他的同学进行了沟通，双方已成为很好的朋友，
他自己本人也不会再为此事而伤心。②在对来访者进行正面积
极鼓励的基础上，进一步引导来访者将此次的认识迁移到生活的
其他方面。③做SDS 测验，标准分为36 分，基本结束咨询。
9．结语: 本案例属于大学校园中较为少见的性别认同障碍而
引起一系列心理问题的案例，具有一定的代表意义。
病区相似药品安全管理存在问题与对策
王波
( 甘肃省白银市第二人民医院神经外科
730900)
【摘要】目的
加强病区相似药品的管理，确保患者用药安全。方法
2012 年1 月针对医院病区相似药品管理中存在的问题进行原因分析，通
过强化护理人员风险意识，健全相似药品安全管理制度，病区设立药品安全管理质控员，加强对低年资护士、新入科护士安全用药的培训，做好用药
知识宣教等措施，加强了病区相似药品的管理。结果
与2011 年相比，2012 年发生相似药品管理缺陷下降，护理人员防范意识增强。结论
加强病
区相似药品管理，强化风险意识，规范操作流程，提高护理人员对相似药品的认知和管理能力，拓宽用药知识，引导护士正确执行医嘱，严格查对制
度，可以减少相似药物差错，提高护理质量。
【关键词】病区; 护理人员; 相似药品; 安全管理
随着医药领域科学迅猛的发展和人群用药量的不断增加，新
药品种大量走进医院临床，药品同音、相近、相似药品种类繁多，
在使用中稍有疏忽极易发生药品混淆事件，护士作为临床药品的
保管者和直接使用者，风险高责任大，如何提高护理人员对相似
药品的安全使用，确保患者安全是护理管理者应该重视的问题。
2012 年1 月我院护理部针对全院各病区在相似药品管理中存在
的问题，加强病区相似药品的安全管理，取得了较好的效果。现
报告如下:
1．临床资料: 收集2010 年1 月至2011 年12 月我院护理质
量控制小组对全院15 个临床科室的检查资料，发现与用药有关
的82 起，其中涉及相似药品的36 起，占43 % 。具体表现为领药
错误6 起，占7% ，摆药错误11 起，占13% ，剂量错误12 起，占
15% ，用药错误7 起，占8．5% ，2011 年12 月护理部对相似药品
的管理制度及常见相似药品的药理作用、用法、用量、注意事项进
行抽查，抽考护士130 名，70 分以上护士仅为35% 。
