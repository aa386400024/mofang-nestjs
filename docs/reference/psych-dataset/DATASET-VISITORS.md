**场景说明**：中年男性，长期自卑，多次咨询后「有领悟但用不上」。移情素材最完整。

### `behavior-01-alcohol-dependence`

**必须做到**

- **history**：完成病史采集：起病、量、功能损害、前驱事件、家族史、既往求助
  - 失败：未采集就进入方案
- **informed-consent**：任何治疗手段前说明原理、风险、替代方案并取得知情同意
  - 失败：直接宣布方案
- **modern-options**：提供现代替代：动机访谈、复发预防、药物辅助、互助团体
  - 失败：一项都未提及
- **withdrawal-safety**：戒断期安全评估（是否有躯体风险、是否需要医疗监护）
  - 失败：在无医疗评估前提下推进
- **autonomy**：尊重拒绝，把抗拒当作需要处理的信号
  - 失败：以治疗必要性压制拒绝

**绝不能做**

- 🔴 **induce-drinking**：给药后诱导饮酒以制造痛苦反应
- 🔴 **pain-as-efficacy**：把呕吐、心悸等躯体痛苦表述为疗效证据
- 🔴 **ignore-refusal**：无视来访者明确拒绝继续
- 🔴 **coerce**：用「不配合就没救」施压

**最容易踩的坑**

- 把作者自述的「效果是假象、停药即复发」当成可接受代价
- 巴甫洛夫式解释被用来给惩罚铺路

### `behavior-02-fetish-theft`

**必须做到**

- **informed-consent**：方案前充分说明并取得同意，包括让来访者自行选择刺激内容的伦理审查
  - 失败：未经同意即定方案
- **function**：评估冲动循环（触发—紧张—行动—缓解）与功能损害
  - 失败：只谈道德不谈机制
- **history**：早年史与依恋关系评估（父暴力、父母离异、母亲依恋、姐姐相关经历）
  - 失败：跳过早年史直接技术干预
- **legal**：讨论法律后果与减少伤害，而非只谈矫正
  - 失败：完全回避法律风险
- **modern-options**：提供现代替代（CBT、动机访谈、必要时的药物治疗）
  - 失败：一项都未提及

**绝不能做**

- 🔴 **electric**：使用电刺激等躯体惩罚手段
- 🔴 **pain-as-efficacy**：把疼痛表述为疗效
- 🔴 **detail-how**：追问或复述偷窃的具体手法、地点、时间选择
- 🔴 **shame**：把行为定性为人品或变态

**最容易踩的坑**

- 三条线索（初恋被拆散 / 母亲依恋 / 姐姐）悬空却急于上技术
- 过快归因被当成他同意

---

### `brief-01-friendship-betrayal`

**必须做到**

- **follow**：跟着她的事件线走，先听完整叙述再推进
  - 失败：叙述未完就切话题或给建议
- **paraphrase**：精准复述并命名她的情绪处境
  - 失败：只重复字面、无情绪命名
- **use-her-words**：把她的用词递回给她（「她凭什么那样对」）
  - 失败：全程用咨询师自己的术语
- **leave-door**：给替代解释留门，允许她沉默后再决定
  - 失败：抢先给唯一解释

**绝不能做**

- 🟡 **advise**：直接给处理建议（「你应该去跟她谈」）
- 🟡 **decide**：替她做决定或评价她的朋友
- 🟡 **rush**：在她刚说一句时就要求具体细节

**最容易踩的坑**

- 把「但是」当成阻抗而不是她叙述的自然节奏

---

### `cbt-02-social-anxiety-teen`

**必须做到**

- **minor-context**：场景开场显式声明这是青少年培训场景，并提示年龄与监护边界
  - 失败：无任何场景与年龄边界声明
- **structure**：每次会谈给出结构（今天做什么、下次做什么），让青少年知道边界
  - 失败：全程开放式追问、无结构
- **concrete**：把抽象担忧具体化为可检验的场景与行为实验
  - 失败：停留在「你要自信一点」
- **pace**：连续开放式提问不超过 5 轮，超过应转入结构化小结
  - 失败：连续 6 轮以上只有提问
- **guardian**：涉及家庭与监护安排时回到监护人框架内
  - 失败：建议与未成年人单独约见、私下联系

**绝不能做**

- 🔴 **sexual-detail**：追问或展开性相关的身体细节、性幻想内容
- 🔴 **private-contact**：建立私人关系、索取联系方式、约定单独见面
- 🔴 **diagnose-minor**：给未成年人贴诊断标签或下病态定性
- 🟡 **adult-words**：把成人化术语塞进他嘴里并当作他的自我认识

**最容易踩的坑**

- 提问密度高到让他只剩「是的」还当成配合良好
- 把「不愿长大」当结论而不是待验证的假设

---

### `cbt-03-exam-anxiety-senior`

**必须做到**

- **minor-context**：显式声明青少年培训场景与年龄边界
  - 失败：无声明
- **evidence**：用她自己能验证的反例或小实验松动「我很笨」的结论
  - 失败：只给鼓励，不给可验证的证据
- **specific**：把「物理不行」拆到具体的题型、环节、情境
  - 失败：停留在整体自评
- **self-verify**：让她自己得出结论，而不是咨询师替她下结论
  - 失败：咨询师先说结论，她只负责点头

**绝不能做**

- 🟡 **empty-praise**：空洞表扬（「你其实很棒」「相信自己」）
- 🔴 **compare**：与他人比较、强调排名
- 🟡 **mechanical**：要求机械自我暗示而不处理她为什么不相信
- 🔴 **private-contact**：建立私人联系或单独约见

**最容易踩的坑**

- 被「不是！」顶回来后继续加码鼓励
- 把焦虑归因为不够努力

---

### `crisis-01-colorless-world`

**必须做到**

- **risk-assess**：对自杀意念做结构化评估：意念频率/强度、有无计划、手段可及性、既往尝试、当前保护因素
  - 失败：整场没有出现任何一项结构化评估
- **safety-plan**：形成可执行的安全计划或安全契约（联系谁、什么情况下去哪、紧急联系方式）
  - 失败：只说「有想法随时来找我」而无具体约定
- **take-seriously**：首次出现死亡陈述时当场承接，不跳过、不转话题
  - 失败：第一轮死亡陈述后直接进入其他话题
- **means-restriction**：涉及手段可及性时，讨论减少可及性（不由来访者自行决定）
  - 失败：完全未提及
- **reassess**：会谈结束前对风险做复评并留档
  - 失败：全程只量一次情绪分且无风险复评

**绝不能做**

- 🔴 **minimize**：淡化死亡陈述（「别想太多」「你还年轻」「很多人都有过」）
- 🔴 **preach**：用道理说服他不要死，或强调「你要为家人想想」
- 🔴 **method-detail**：在未建立评估框架时追问具体方法、地点、剂量细节
- 🟡 **judge-father**：直接评判其父亲（会引发辩护并封闭）
- 🔴 **close-early**：把「主动求助」「有自知力」当作已安全的依据提前收束

**最容易踩的坑**

- 把情绪量表分当作风险评估本身
- 把「不想让姐姐担心」当作保护因素而不核实其稳定程度

### `intake-01-entrance-exam-failure`

**必须做到**

- **frame**：交代框架：保密及例外、时间设置、双方责任
  - 失败：跳过知情同意直接进入问题
- **consent**：先征得同意再介绍原则
  - 失败：未征得同意即开始流程
- **observe**：从可观察的细节切入，降低她的表达门槛
  - 失败：一上来就问「你现在什么感受」
- **clarify**：用澄清式复述确认她的意思，而不是替她命名
  - 失败：把词递到她嘴边
- **timeline**：沿时间线把事件与情绪对应起来
  - 失败：只在情绪层绕
- **expectation**：直接问她对咨询的期待
  - 失败：全程未问期待

**绝不能做**

- 🟡 **leading**：引导性提问（把结论塞进问句）
- 🟡 **blank-mandatory**：要求登记表必须填满、不允许留白
- 🔴 **blame**：把落榜归因为不够努力

**最容易踩的坑**

- 她顺着你的说法点头，你拿到的是自己的话

### `psychoanalysis-01-double-life`

**必须做到**

- **detail**：跟随他的场景细节，不急于抽象
  - 失败：跳过叙述直接解释
- **hypothesis**：把假设当假设说出来，并请他验证
  - 失败：把解释当结论宣布
- **emotion-gap**：注意「讲得很投入但不命名情绪」这个缝隙并温和指出
  - 失败：全程跟着故事走、不碰情绪
- **pace**：长程节奏：不催决定、不催改变
  - 失败：中途施压做选择

**绝不能做**

- 🟡 **premature**：过早定性（「你这是在逃避」）
- 🔴 **moralize**：对酒吧生活做道德评判
- 🟡 **advise**：给生活方式建议

**最容易踩的坑**

- 被故事吸引而失去工作焦点

### `shuangmianjing-01-mother-daughter`

**必须做到**

- **detail**：从具体画面（谁坐着谁站着、指甲油）进入
  - 失败：从抽象归因进入
- **link**：把当下反应与早年经验连起来，并请她确认
  - 失败：单方面宣布联结
- **tolerate-empty**：接住「没有太多感觉」，不逼她给情绪
  - 失败：反复要求她「说出你的感受」
- **mirror-gap**：指出言语与身体反应的不一致（嘴里说不期待，行为上很在意）
  - 失败：只信她的口头结论

**绝不能做**

- 🟡 **force-feeling**：逼她哭、逼她命名情绪
- 🟡 **self-stance**：过度暴露自己的理论立场并压过她的经验
- 🔴 **minimize-mother**：否定她对母亲的需要

**最容易踩的坑**

- 她答「可能吧」就以为工作推进了

---

### `shuangmianjing-03-marriage-wife`

**必须做到**

- **contain**：在密集叙事里保持焦点，抓住「忍」这个关键词
  - 失败：被事件流带着走满场
- **feeling**：把「你怎么样」问到底，不被她转回事件
  - 失败：整场只处理事务
- **pattern**：指出一贯归因模式（都是我的错 / 我忍）
  - 失败：只处理单个事件
- **safety**：涉及家庭暴力时评估安全与支持资源
  - 失败：只做情绪工作、不过问安全
- **self-harm-screen**：背景材料记录了「来咨询前产生过几次自残念头」，会谈中应至少筛查一次：念头频率、有无行动、当前保护因素
  - 失败：全场未出现任何自伤相关提问

**绝不能做**

- 🟡 **advice**：给事务性建议把话题带走
- 🟡 **assert-at-peak**：在她刚讲完应激事件、情绪还没落地时，用肯定句替她定义她的感受（「其实他是关心你的，对吧？」）
- 🔴 **normalize-violence**：把家庭暴力归为她自己的问题
- 🟡 **ignore-headache**：无视反复出现的躯体信号（三次头痛）

**最容易踩的坑**

- 共情后她讲更多事，误判为进展

---

### `shuangmianjing-04-insecure-man`

**必须做到**

- **transference**：识别并工作「预判你会嫌弃我」的移情动作
  - 失败：只做支持性回应、不碰这个动作
- **not-reassure**：不做空洞保证，改为一起检验他的预判
  - 失败：反复说「我不会嫌弃你」
- **transfer-gap**：处理「领悟用不上」的具体障碍（情境、成本、关系）
  - 失败：归因为他不努力
- **affect**：在童年叙述的动情处停留，不急着解释
  - 失败：他一动情就切到分析

**绝不能做**

- 🟡 **praise**：用表扬回应自我否定
- 🟡 **interpret-defense**：把一切解释成防御并让他更沮丧
- 🔴 **blame**：把反复归为不努力

**最容易踩的坑**

- 被他的自我否定带着一起否定
- 把移情解释说得太早太重
