## 0. 口径与假设

- 本里程碑只覆盖 **A 口径：能上线内测/收第一批反馈的核心产品**，不含 Phase2 完整（B端工作台/UGC/流派/MindGuard/万级并发）与 Phase3/4 生态。
- 假设：WP6 已在后端开工；现有 `src/llm` provider 可用；CPU 部署；无专业审核委员会（角色/剧本先按专业口径自审，内测后再请人校）。
- 周数为**相对周**（W1 = WP6 交付当周起算），不绑定日历日期；每周结束对照"验收卡点"决定是否进入下一周，不硬赶。

## 2. 逐周明细

### W1 · WP6 RenderPort 适配 + 主备执行
- **产出**：`LlmRenderAdapter` 交付核验；主失败切备、冷却、恢复切回、block 降级；adapters 单测绿、engine-core 177 零回归。
- **依赖**：已注册 provider 的 key 可用、网络通。
- **卡点**：主 provider 超时/报错是否被正确归一为"可切备"；鉴权失败不误循环。

### W2 · WP7 规格组装 + turn 填 reply
- **产出**：从 EngineTurnOutput 组装 `RenderSpec`（意图/情绪/阻抗/移情/核心信念/recall/轨迹注记/历史），`fitContextToBudget` 裁剪；调 WP6 渲染并把文本填进 `reply`；适配层中文来访风格 prompt；问+答成对写工作记忆。
- **卡点**：回复不越出 intention/禁止行为；单轮 token 不超预算；渲染失败有兜底不断流。

### W3 · WP8 接会话 + 流式 + 灰度切换 → M1
- **产出**：编排层持有 EngineSessionPort + RenderPort；`streamChat` 增量推给现有 WS/SSE 语音链路；新引擎与旧 visitor 直出可按开关切换、可一键回退；开场/aborted/断流处理。
- **M1 验收**：咨询师发一句 → 来访流式逐字回一句 → 出参可见 BDI 快照变化；既有语音播放/落库不破；开关可切回。

### W4 · WP9 角色资产池 V1 ｜ 并行 WP12 记忆收尾
- **主线**：5Ps schema 落 MySQL（手写 migration）、3–5 个初始人设、openSession 注入基线、未审核不可用。
- **并行**：QdrantService 补 setPayload/scroll 做写侧冲突标记；短时记忆自动摘要写入 + 会话结束晋升长时；衰减半衰期/阈值给配置化标定口径。
- **卡点**：同一角色多次开场基线一致；migration 可回滚；晋升后可被 resume 召回。

### W5 · WP10 盲盒剧本 ｜ 并行 WP11 PsyGUARD
- **主线**：10 个伦理/危机盲盒按 TrajectoryScript 落成资产，强覆盖可复现，开场校验非法剧本。
- **并行**：独立 Python FastAPI（RoBERTa 11 类，CPU <50ms）+ NestJS `RiskProbePort` 适配 + 超时降级规则；规则词典补全、全半角归一。
- **卡点**：同一盲盒两次演练触发点/关键表现一致；PsyGUARD 挂掉自动回落规则不阻断对话。

### W6 · 安全回归 + 标定 + 自审 → M2
- **产出**：block 不传出全路径复测；记忆参数标定口径定稿；角色/剧本按专业口径自审（标注"待专业复核"）；warn/block 有审计日志。
- **M2 验收**：规则+PsyGUARD 双层在位、记忆闭环、内容资产可开场。

### W7 · WP13 基础可观测
- **产出**：每轮决策链留痕（事件/快照delta/intention/轨迹trace/provider/usage/安全verdict）；基础指标（延迟/token/fallback率/安全命中）；单会话 BDI 状态变化可回放。
- **卡点**：留痕不抄敏感原文（片段截断同 WP4）；指标可统计 fallback/安全命中。

### W8 · 前端联调 + 第一轮调参
- **产出**：流式、报告、督导提示回显与新引擎对齐；人设漂移/口语风格/情绪位移第一轮调参；成本基线记录。
- **卡点**：连续多轮不崩、不串角色、不出现违规引导。

### W9 · 内测打磨 → M3
- **产出**：边界异常（空输入/超时/中止/极端文本）、延迟与成本调优、回归修复；内测准入清单全绿。
- **M3 验收**：见 §4。

### W10 · 缓冲机动
- 留给模型风格调试、真实问题返工；不预排新功能，避免挤占闭环。

## 3. 不可压缩项（不靠写代码速度）

1. **角色/盲盒剧本专业打磨**：AI 出初稿，需按心理咨询口径校核，内测后再请专业人复核。
2. **人设漂移与口语风格调参**：接真实模型后才暴露，迭代轮次不可提前压缩。
3. **安全误判/漏判回归**：危机识别代价高，需覆盖样本反复测。
4. **成本与延迟基线**：上线后才测得准。

## 4. 内测准入清单（M3 Definition of Done）

- [ ] 连续 10+ 轮对练不断流、不崩、不串角色；
- [ ] 主模型故障自动切备不中断，恢复后切回；
- [ ] 输出 block 高危文本绝不传出，warn 有记录；
- [ ] 至少 3 个可开场角色、1 个盲盒可复现演练；
- [ ] PsyGUARD 服务挂掉自动降级规则，对话不阻断；
- [ ] 会话结束记忆晋升，下次 resume 能承接；
- [ ] 单会话决策链可回放，fallback/用量/安全命中可统计；
- [ ] 既有前端语音播放、历史落库不破；无阻断级 bug。

## 5. 风险与回退

| 风险 | 应对 |
|---|---|
| 真实模型人设漂移/不像 | W2 起保留规则兜底短句；漂移严重先降温度/收敛 prompt，不硬调内核 |
| 主备/provider key 不稳 | W1 先打通单 provider，主备第二候选后置；鉴权失败直接降级 |
| PsyGUARD CPU 性能/部署拖期 | W5 可后置，规则层先顶，服务到位再接 |
| 某周超期 | 砍非关键（观测美化、高级模型），保 M1 闭环优先 |
| 旧链路不可丢 | W3 起保留开关回退，灰度不切死 |
