# v1.3 自由练习引擎前端落地进度 (2026-10-22)

## 背景
v1.2 专项技能详情页原来每个技能只有一道固定选择题, 无法支撑「多场景练习」诉求。
本阶段把 10 个专项技能从单场景 MCQ 升级为 **多变体自由练习场**, 与 v1.3 spec 对齐。

## 本次已落地 (前端 xin_su_app)

### 2. 三引擎 bloc 状态机
- `bloc/exercise_practice_bloc.dart`: 场景索引 + Next / Retry 事件
- 练习页 `view/exercise_practice_page.dart`: 文本输入回应 + 完成按钮
- 列表页 `view/training_exercise_list_page.dart`: 随机胶囊 + 每 skill 入口

### 3. Hub 双卡入口 (specialized-skills-detail-route)
位置: SummaryCard 下方, 3 大类卡上方
- `_RandomCard`「随便练一题 / 不确定练哪个」: 珊瑚粉柔色渐变 (auxMistyPink 22% → Soft), 3D 气泡插画
- `_RealCaseCard`「真实情况？/ 当场还原重练」: 薄荷青柔色渐变 (auxMintCyan 22% → Soft), 3D 书本对话插画
- 视觉规范: 白底圆角 + cardShadow, 左文右图, 文字深色不换行, 图 80dp
- 资产: `assets/images/training/entry_random_3d.webp` / `entry_real_case_3d.webp`

### 4. 真实情况三问 BottomSheet
- `lib/features/counselor_home/view/widgets/real_case_entry_sheet.dart`
- 三问: 来访说了什么 / 你卡在哪 / 你希望 AI 怎么演
- 提交后写入 `PracticeContentLocalSource.pendingCustom`, 进入练习页
