## 4. ✅ VS-B2 拍板结果（2026-10-21 21:05 大炮拍板「按你推荐的来」，已落地）

### ① 接线方案 = B（依赖倒置 + provider token）— 实际落地多了一步

原方案 B 的 provider token **直注会循环依赖**（counselor→agent 取 LlmModule，agent→counselor 成环），
所以落地为 **@Global 的 `VisitorContextRegistry` 注册表**：

- agent 侧只提供插槽（`VisitorContextContributor` 接口 + 注册表），**0 处 import counselor**
- counselor 侧实现 `CounselorVisitorContextContributor`，在 `onModuleInit` 注册进注册表
- `VisitorService` 每轮调 `registry.resolve(sessionId)` → 业务块进 system prompt
- 业务块可**替换**通用画像（`replacesPersona`）+ 覆盖难度/身份（`difficulty` / `identity`）

### ② 长程来访者走哪条链 = 语音链路保持通用 + sessionId 绑定契约

语音链路（ASR/TTS/visitor）**不重造**；约定：

> **训练/长程会谈的 voice WS `sid` = counselor 的 `sessionId`**

贡献者按该 id 反查 counselor 会话（`SessionContextBuilder.loadBySessionId` 自动判定单次/长程）并注入上下文。
**前端只改 1 处**：连 voice WS 时用 counselor 的 sessionId 当 sid。

### ⚠️ 本片修订了 D9

原 D9「tier=off 时不采集」→ 改为「**分析始终跑**，档位只控 hint 是否落库 + 推送」
（否则档案永远不填 → 信任度永不涨 → M1 机制失效）。详见 spec §14 D19。

## 6. 后端硬约束（写代码前必看）

1. **migration 三处注册**：`bin/ormconfig.ts` import + `migrations[]` 数组 + `src/migration/index.ts` export。漏了静默不建表。
2. **counselor 系 migration 一律手写 DDL**：`bin/ormconfig.ts` 的 entities glob 只覆盖 `src/entity/**` 的 sampledb，
   `migration:generate` **扫不到 counselor 系 entity**。
3. **软删不是 `@DeleteDateColumn`**：counselor 10+ entity 全用普通 `deleted_at` 列 → 每处查询手写 `deletedAt: IsNull()`。
4. **同名符号要跨文件查重**：domain interface 与 entity class 曾同名（`VisitorFullPersona`）→ tsc TS2300 级联炸 27 个错。
   已改为 `VisitorFullPersonaScript`（剧本内容）vs `VisitorFullPersona`（表行）。
5. **项目 tsconfig 开了 3 个会咬人的开关**：`noUnusedLocals`（未使用 import = **错误**）·
   `noPropertyAccessFromIndexSignature`（索引签名属性必须用 `obj['x']`，点访问报 TS4111）· `strict`。
6. **结构化输出只有一条链**：一律走 `CounselorLlmJsonClient`，不新建第二套 JSON 提取。
7. **`.env` 的 `MINIMAX_LLM_MODEL` / `MINIMAX_BASE_URL` 是 ASR/TTS 共用值，不许动**
   （改 `.cn` 会打断语音链路）；模型差异用 per-call 覆盖（`MINIMAX_COUNSELOR_LLM_MODEL`）。
8. **M3.1-Flash 忽略 `temperature` / `top_p`** → 确定性靠 prompt 约束 + `reasoning_effort` 分档；
   **thinking token 计入生成长度上限** → 结构化 JSON 必须用 `max_completion_tokens` 并留足余量。
9. **不自动 commit / push**：写完给 commit 文字，等大炮指令。
10. **偏好表的键白名单拦不住"已知键 + 非法值"**：`prefs` 值类型放宽为 `boolean | string` 后，必须按键加**值白名单**
    （如 `liveSupervisionHintTier` 只收 `light` / `off`），否则脏档位会让业务分支不可预期。
11. **SSE 事件总线是进程内的**（`SessionCoreEventsService`）：多实例部署时事件只推给连在本实例的客户端 → 升级路径 = Redis Pub/Sub
    （仓库当前无任何 pub/sub 频道，属独立改造范围）。
12. **异步任务的偏好要在「执行时」读，不在「入队时」读**：入队到执行可能隔几秒，用户中途改的偏好要能立刻生效。
13. **jobId 要幂等**（`ta-{sessionId}-{turnIndex}`）：重试/重传不能堆重复 job。
14. **agent 与 business 之间只走 @Global 注册表，provider token 直注会成环**：
    counselor→agent 取 LlmModule，agent→counselor 就成循环依赖。
15. **业务上下文块要能"替换"通用画像，不能只追加**：两套人设并存会让模型选择性忽略，行为不可预期。
16. **"档位"只控展示，不控是否分析**：档案抽取 / 信任度推进 / 移情标记是卷宗数据，对关掉提示的用户同样有价值。
