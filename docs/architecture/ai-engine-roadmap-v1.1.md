## 0. 第 0 原则：引擎未来独立成微服务

引擎（BDI / 记忆 / 轨迹 / 伦理 / 渲染调度）后期要能**单独抽离成对外服务**（开放 API、供第三方调用）。这条先于一切功能设计：

1. **纯 TS 内核不依赖 NestJS 传输层**：内核只放领域模型、状态机、算子、接口；不直接 import `@nestjs/*`、不直接碰 TypeORM 实体。
2. **持久化走 repository 接口反转**：内核定义 `XxxRepository` 接口，内存实现 / MySQL 实现 / Qdrant 实现可替换；NestJS 只做适配器（WS、鉴权、落库、HTTP）。
3. **进程边界预留**：Python 伦理推理服务天然独立进程；TS 内核未来整包搬走，只换适配器即可对外暴露 HTTP/gRPC。
4. **内核无全局单例/进程内总线硬编码假设**：会话状态、事件、缓存的存取都经接口，为多实例/独立部署留口。

> 反双胞胎：不要在内核里直接 `@Injectable()` + 直连 Repository 实体；那样将来拆服务时内核和框架缠死，搬不动。

## 0.5 决策与渲染边界铁律（不可突破）

承接《BDI 认知引擎最终设计原则》并结合本仓纯规则内核实际，固化为不可突破的边界。两份原则文档（骨架-血肉分离、静态-动态分离、统一门面）已由 §0 与 WP0 内核边界落地，此处只补尚未成文的约束。

1. **可控优先于逼真**：当"更逼真的复杂规则"与"可复现 / 可调试 / 可预测"冲突，无条件保可控。心塑是专业实训平台（能练、能考、能进步），不是聊天陪伴；一个效应只提升 5% 真实感却使复现性下降，就不进 BDI。
2. **决策层确定、表达层随机**：相同输入 + 相同状态必须得到相同意图（考核公平、伦理盲盒可复现）；随机只允许出现在渲染层的措辞 / 停顿 / 句长，核心行为策略与阻抗数值 100% 一致。
3. **模型绝不回写状态**：BDI 状态只能由纯函数算子迁移；LLM 只把结构化意图渲染成口语，无权更新阻抗 / 信念 / 移情 / trust。内核零 LLM、零网络、零 prompt，由 `test/engine-core/boundary.spec.ts` 机器断言。
4. **需求驱动，不堆理论**：任何算子 / 心理效应必须对应明确实训场景（训练包 / 伦理盲盒 / 考核题），无场景的理论不提前编码；新增算子走 §4.5 准入闸门，防止 BDI 膨胀成规则黑盒。
5. **真实感全在渲染层**：阻抗-表达映射、口语化 / 停顿、表达层轻量随机、情绪粒度细化都属渲染 prompt 优化，不进决策层（见 §4.6，Phase2）。75 / 80 / 85 / 90 真实感分为**定性方向，非实测硬 KPI**，待专业评审 + 用户盲测校准，不写进验收指标。

## 1. 现状基线（2026-10-28 扫描）

### 1.1 现有技术栈（已具备，复用不重造）

| 能力 | 现状 | 复用点 |
|---|---|---|
| 后端框架 | NestJS 11 + Express + WS(`@nestjs/platform-ws`) | 适配层/传输 |
| 主数据库 | MySQL 2 + TypeORM（migration 手写，禁 synchronize） | 业务/会话/档案落库，**不改库** |
| 向量 | `@qdrant/js-client-rest`，目前仅服务 `ai-engine` 知识库 RAG / knowledge-base | 长时记忆另开独立 collection |
| 缓存 | ioredis | 热点会话状态/锁/限流 |
| 异步队列 | BullMQ | 每轮分析、报告、降级任务 |
| LLM | `src/llm/` 多 provider 路由（openai-compatible / deepseek / doubao / qwen / custom）+ 流式 | 渲染调度底座 |
| 语音 | ASR 上传、TTS bidi 双工、`voice.gateway` 桥、`vpt-session-bridge` 落库 | 会话传输不动 |
| 旁观分析 | `turn-analysis.service` 一轮一次 LLM 出「轻提示+移情阻抗标记+档案抽取」 | 督导侧保留，与来访 BDI 分离 |
| 安全 | `emergency` 模块、`crisis-detector`、`zero-pressure.guard`、规则禁言 | 伦理规则层雏形 |

### 1.2 来访生成现状（为什么说还不是引擎）

链路（`src/agent/visitor/visitor.service.ts` + `visitor.prompts.ts`）：

> persona 快照 + 20 条滑窗历史 + `emotionBaseline` 字符串 + 难度 behavior 文字块 → 拼 system prompt → LLM 流式直出。

关键缺口（即"对接式 Prompt 扮演"）：

- 情绪只是 prompt 里的文字规则，`currentEmotion` 是自由字符串、**不被解析为状态变量**；
- **没有信念/愿望/意图三层结构**，来访"说什么"由模型临场发挥，无内部决策；
- 阻抗/移情是**咨询师侧事后打 tag**（`transference-mark`），不是来访自身可量化、驱动回复的状态；
- 记忆只有 per-session 内存滑窗（`VisitorSessionMemory.messages`，20 条上限），**无三级记忆、无向量召回、无遗忘/冲突消解、无跨会话接续**；
- 无"先结构化决策、后语言渲染"的分离，专业推理全压给模型幻觉；
- 轨迹只有 drills 固定文本脚本（边界/危机），无强覆盖/修正/触发三模式；
- 伦理非三层，无来访**输出侧**校验、无会后专项审计。

## 2. 已拍板技术决策（ADR 摘要）

| # | 决策点 | 结论 | 理由 |
|---|---|---|---|
| D1 | 主数据库 | **维持 MySQL2 + TypeORM，不迁 PostgreSQL** | 现网稳定、migration 体系成熟；避免迁移工程 |
| D2 | 向量库 | **保留 Qdrant，不换 pgvector**；长时记忆新建独立 collection（如 `visitor_long_memory`），与知识库 RAG 隔离 | 引擎要独立成服务，记忆向量不应绑业务库同库；Qdrant 专为向量检索优化，SDK 已装 |
| D3 | 编排框架 | **Phase1 不上 Mastra**，用 NestJS 内手写结构化状态机+事件驱动；内核按"可替换编排层"设计，Phase2+ 再迁 Mastra | 先立 BDI 地基，避免一上来背重型框架 |
| D4 | Python 模型形态 | 独立 Python 推理微服务（FastAPI），NestJS 内部 HTTP 调用，带健康检查/超时/降级 | HF 模型无法在 NestJS 内跑；独立进程也契合可抽离方向 |
| D5 | 模型硬件 | **PsyGUARD-RoBERTa（11类风险）CPU 可跑**（小分类器，单条 <50ms，4C8G 常驻）；**MindGuard 4B/8B 纯 CPU 跑不动实时**，后期走云端 API，本期只占位 | 避免在 CPU 服务器上承诺大模型实时 |
| D6 | Phase1 范围 | **激进铺开**：BDI + 记忆V1 + 规则伦理 + 轨迹三模式同批推进，按依赖排序并行，不挤牙膏 | 用户明确要求 |

### WP0 · 内核边界与骨架（最先做，一切的地基）

> 🟢 **纯层已交付（2026-10-28）**：`src/engine-core/` 物理隔离、纯输入输出 DTO、内存仓储实现、边界断言；内核零 `@nestjs/` / typeorm 直连。端到端装配见 backlog WP6+。

- **目标**：把引擎内核从 NestJS 里物理隔离出来，落实第 0 原则。
- **内容**：
  - 新建纯 TS 内核目录（建议 `src/engine-core/`，无 `@nestjs` import），放领域模型/状态机/接口；
  - 定义 `VisitorBdiRepository` / `MemoryStore` / `TrajectoryStore` 等接口，先给内存实现；
  - 定义会话内核的纯输入/输出 DTO（不沾 HTTP/WS 帧）；
  - NestJS 侧只留适配器把 WS 帧翻译成内核调用。
- **验收**：内核单测不启动 NestJS 即可跑；内核源码 `grep` 不到 `@nestjs/`、`typeorm` 实体直连。
- **不做**：不写具体 BDI 算法（WP1），只立边界。

### WP1 · BDI 认知引擎（核心护城河）

> 🟢 **纯层已交付（2026-10-28）**：规则轨事件分类、状态迁移、意图派生、阻抗/移情量化快照、可复现基线；5Ps 角色真实注入与"先决策后说话"的渲染接线留待 backlog WP7/WP9。

- **目标**：来访从"prompt 扮演"变成"先决策后说话"。
- **三层结构**（借 LifeSim 理论 + classic-agents 工程循环）：
  - **信念层 Belief**：核心信念（源自角色内核 5Ps，永久不可变）/ 短期信念（会话中形成，带置信度，可被咨询师干预改变）/ 记忆信念（长时召回，带时效）；
  - **愿望层 Desire**：底层愿望（被理解/被接纳/回避痛苦/掌控感）+ 情境愿望（本轮具体诉求），带权重与优先级，随信念变化；
  - **意图层 Intention**：本轮行为目标 = 行为策略 + 情绪状态 + 阻抗等级 + 移情等级 + 禁止行为，五字段结构化。
- **事件驱动状态演化**：把咨询师行为/场景变化抽象为标准会话事件——正向（共情/接纳/正常化→降阻抗、提信任/开放）、负向（评判/说教/打断/越界→升阻抗、触发防御）、触发（碰创伤点/提敏感议题→情绪波动+防御激活）。**Phase1 全部走纯函数规则轨**（内核零 LLM / 零网络，模型不回写状态，见 §0.5-3）；上游蓝图提的"复杂场景模型微调"不作为决策轨，不进内核、不更新状态，后期仅可作为渲染 / 评估增强另行评估。
- **阻抗三维量化**（借 PatientHub）：话量阻抗（回复长度）/ 内容深度阻抗（自我暴露程度）/ 表达风格阻抗（语气疏离对抗），数值化直接喂给意图层。
- **移情量化**：正移情/负移情/依赖移情三态，随关系动态变化。
- **验收**：同一角色同一咨询师行为序列，BDI 状态可复现快照；意图层五字段结构化落库/进日志；模型只负责把意图渲染成口语，不自行改状态。
- **不做**：多流派差异化参数（Phase2）。

### WP2 · 分层记忆引擎 V1

> 🟢 **纯层已交付（2026-10-28）**：工作窗口裁剪、重要度衰减、冲突消解纯函数、短时→长时晋升纯函数、Qdrant B 层（`visitor_long_memory` 语义 Top5 召回 + 软降级）。⚠️ 遗留：Qdrant 写侧冲突标记（缺 setPayload/scroll）、短时记忆自动摘要写入与会话结束晋升接线、半衰期/阈值未标定 —— 见 backlog WP12。

- **目标**：三级记忆 + 长时向量召回 + 跨会话接续。
- **内容**（借 AnnaAgent 三级记忆 + 情绪累积衰减）：
  - 工作记忆：当前回合上下文，最近 8 轮，直接参与本轮决策；
  - 短时记忆：单会话完整摘要，伴随全程，会话结束转长时；
  - 长时记忆：跨会话核心事实/情绪体验/关系变化，存 Qdrant 独立 collection `visitor_long_memory`；
  - 写入：每轮结束自动生成摘要+向量入库；检索：新回合按当前议题语义召回 Top5，过滤过期/冲突；
  - 遗忘：重要度随时间衰减，低重要度不再召回；冲突消解：以时间更近、置信度更高为准并记录冲突点；
  - 跨会话接续：恢复时加载 BDI 快照（情绪/阻抗/移情）+ 核心议题进度 + 关系状态 + 高权重长时记忆，生成本场开场白。
- **验收**：同角色跨两次会话，第二次开场能承接上次议题/情绪；召回 Top5 可审计；内存实现可平滑换 Qdrant 实现（WP0 接口）。
- **不做**：竞争抑制遗忘的精细权重（Phase2）、Chinese-MentalBERT 专用向量（先用现有 embedding）。

### WP3 · 会话轨迹控制引擎（三模式）

> 🟢 **纯层已交付（2026-10-28）**：强覆盖/修正/触发三模式纯函数、线性游标、触发评估、终态判定、Trace 观测。⚠️ 遗留：10 个伦理盲盒真实剧本资产未建、暂停/恢复/归档持久化留装配轮 —— 见 backlog WP10。

- **目标**：标准化训练场景可复现，伦理盲盒每次触发点一致。
- **三模式**（基于 PatientHub 进程节点 + AnnaAgent 阶段划分）：
  - **强覆盖**：预设行为目标完全覆盖 BDI 输出，来访严格按剧本（标准化考核/伦理盲盒）；
  - **修正**：预设目标对 BDI 输出加权修正，主线不偏、保留灵活（专项训练包）；
  - **触发**：平时 BDI 自由运行，满足触发条件才激活对应节点（隐藏伦理坑/突发危机）。
- **剧本结构**：基础元数据（适配角色/场景/难度/训练目标）+ 节点序列（触发条件/行为目标/参考素材/状态偏移量）+ 退出机制（完成判定/异常分支/结束条件）。
- **验收**：伦理盲盒反复演练，触发点/表现/风险点一致可衡量；三模式可切换；轨迹进度可暂停/恢复/归档。
- **不做**：UGC 剧本提交审核流（Phase2）。

### WP4 · 伦理安全引擎（规则 + PsyGUARD，双层起步）

> 🟢 **规则纯层已交付（2026-10-28）**：双侧 `assessSafety`（咨询师输入/来访输出）、规则引擎、`RiskProbePort` 占位、本场 warn/block 事件累计与会话报告。⚠️ 遗留：PsyGUARD-RoBERTa 独立 Python 服务未建、规则词典未标定、全半角未归一、报告随句柄释放需 close 前取走并落库 —— 见 backlog WP11。

- **目标**：全链路防护，覆盖咨询师输入与来访输出双侧。
- **内容**：
  - **规则层**（本期主体）：关键词/正则/语义模板硬规则，毫秒响应；禁言（给建议/承诺治愈/价值审判/双重关系）、高危（自杀自残指导/违法/歧视）；
  - **PsyGUARD 层**：独立 Python FastAPI 服务加载 `PsyGUARD-RoBERTa`（11类细粒度风险：自杀行动/意念/自伤/攻击/受虐等），CPU 部署，单条 <50ms，NestJS HTTP 调用 + 超时降级到规则；
  - **双侧检测**：既查咨询师输入，也校验来访输出不生成违规引导；
  - **会后**：全量对话复盘生成伦理风险报告，纳入实训档案；
  - **MindGuard 临床层**：本期只留接口占位，后期接云端 API。
- **验收**：规则层拦截明确越界；PsyGUARD 服务挂掉自动降级规则不阻断对话；高风险拦截有日志可审计。
- **不做**：MindGuard 本地部署、4B/8B 自托管（后期云 API）。

### WP5 · 多模型渲染调度（贯穿）

> 🟢 **渲染契约纯层已交付（2026-10-28）**：`RenderTaskKind`/`RenderSpec`/`RenderResult`/`RenderPort` 纯接口、Token 预算裁剪纯函数、`selectFailoverTarget` 纯选择、`guardVisitorOutput` 输出侧薄封装；内核零 LLM/零网络/零 prompt。⚠️ 遗留：RenderPort 无真实实现、无规格组装器、turn 未填 reply、无流式接线、主备只"选谁"未执行冷却/退避/恢复切回 —— 见 backlog WP6/WP7/WP8。

- **目标**：结构化意图 → 自然口语；成本与容灾可控。
- **内容**：
  - 约束注入：把行为目标/人设约束/伦理要求结构化注入 prompt，确保不偏离决策；
  - 流式输出：SSE/WS 双协议适配现有语音播放；
  - 任务分层：结构化推理（状态更新/意图/摘要）用低温稳定模型，对话生成用高温流式，复杂检测按需调高阶；
  - 主备容灾：主模型异常自动切备用，恢复后切回，业务无感；
  - Token 预算：单轮上限 + 记忆片段/历史动态裁剪。
- **验收**：主模型故障一次自动切换不中断；单轮 Token 有上限告警；渲染内容不越出意图层目标。

## 4.5 算子分级与拓展准入闸门（防 BDI 膨胀）

> 来源：《BDI 认知引擎最终设计原则》§4.3 / §5。本仓 Phase1 只落地 P0；分级是治理结构，不是现在就要写满算子。

**算子分级（按需启用，不提前编码）**

| 级别 | 分组内容 | 启用阶段 | 说明 |
|---|---|---|---|
| P0 核心算子（必选） | 基础会谈事件、三维阻抗计算、基础移情、核心信念保护 | **Phase1 强制（WP1 已落地）** | 保证逻辑自洽的最小集 |
| P1 人格调节算子（进阶） | 依恋调节、人格特质调节 | Phase2 默认 | 同样共情，安全型/回避型信任增量不同 |
| P2 社会心理算子（扩展） | 权威关系、社会评价 | Phase3 按需 | 仅在对应训练包需要时开 |
| P3 专项算子（小众） | 发展阶段、细分防御（如创伤专项） | Phase4 按需 | 绑定专项训练包，不进通用内核 |

**新增算子准入三要素（缺一不可）**：① 有明确产品实训场景（训练包 / 盲盒 / 考核题，说清"学员练什么、为什么需要这个效应"）；② 有专业校准依据（成熟理论 + 专业顾问确认临床逻辑）；③ 有可量化验收（输入事件 → 输出状态变化范围，可写自动化测试）。

**五步评审**：提交《算子拓展申请》（场景 / 理论 / 系数范围 / 测试用例）→ 专业评审（临床合理性）→ 技术评审（无规则冲突、不破坏可复现、可观测可回溯）→ 回归基线（全部既有用例绿）→ 灰度（指定角色 / 场景先开，稳定再扩）。

## 4.6 渲染层真实感手法（全在渲染层，不碰决策）

> 来源：BDI 原则 §6。这些是 Phase2 渲染优化方向，阈值均为经验种子值，需真实对练校准，不写死进决策算子。

- **阻抗-表达映射**：渲染层按三维阻抗数值控制句长 / 内容深浅 / 态度软硬（高阻抗→短、浅、硬，甚至沉默），数值由 BDI 出，表达分寸由渲染定；
- **口语化与非语言**：渲染 prompt 约束口语化、避免书面/总结话术，高阻抗加停顿/沉默/语气弱化，激动可有重复、改口、话说一半；
- **表达层轻量随机扰动**：核心策略与阻抗值 100% 一致，仅措辞、是否停顿、句长小幅随机，避免机械重复；
- **情绪粒度细化**：BDI 只出核心情绪（如"难过"），渲染结合阻抗/记忆细化为隐忍、哭腔、放松倾诉等表达。
- **operatorTrace（本轮触发了哪些算子）** 不单独立项，并入 WP13 可观测留痕，供专业调试与考核回放。

## 6. 数据与记忆设计要点

- **角色内核域（MySQL）**：基础属性 + 5Ps（主诉/易感/诱发/维持/保护因素）+ 人格沟通/阻抗基线 + 专业标签 + 版本管理/审核状态；核心信念永久不可变。
- **会话状态域（MySQL + Qdrant + Redis）**：BDI 状态快照、轨迹进度、轮次明细、统计指标；热状态放 Redis。
- **记忆数据**：短时与会话绑定结构化摘要；长时存 Qdrant `visitor_long_memory`（向量+内容+重要度+时间戳+来源标签），与知识库 RAG collection 隔离。
- **业务流水域（MySQL + 归档）**：会话记录、轮次、审计日志，冷数据定期归档。
- **治理**：字段/枚举/标签统一；入库质量校验；角色/剧本/标尺多版本可回溯；用户对话脱敏、不用于训练、支持删除；操作全量审计。
