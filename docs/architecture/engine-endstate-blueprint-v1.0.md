# AI 来访仿真引擎 · 终局形态白皮书 V1.0

> **路径**：`docs/architecture/engine-endstate-blueprint-v1.0.md`
> **性质**：北极星参考 —— 不是任务单，不是路线图，是"最终我们要做成什么样"的共识锚点。
> **用法**：每做一个 Phase / 每拍一个方向，回头看一眼：现在离终局还有多远？这个决定是在往终局走还是在绕路？

## 0. 一句话定义

**一套临床级可信、工程级可控、对标专业心理咨询师执业训练标准的 AI 来访仿真引擎。**

它不是"更聪明的聊天机器人"，是"可以拿来训练心理咨询师执业能力的仿真系统"——就像飞行模拟器训练飞行员，而不是陪你玩的模拟飞行游戏。

---

## 1. 对标坐标（我们要成为谁）

| 维度 | 对标对象 | 我们要达到的水平 |
|---|---|---|
| **学术理论** | BDI 经典模型（Rao & Georgeff, 1995）+ PRS 推理系统 | 完整的感知→信念更新→愿望生成→意图选择→计划执行闭环，不是简化版状态机 |
| **临床深度** | 循证心理咨询核心模型：同盟模型（Bordin）、依恋理论（Bowlby/Ainsworth）、阻抗模型（Mills）、移情/反移情 | 关键临床构念都有可计算的状态变量，不是 prompt 里写几句"他应该有点阻抗" |
| **工程标准** | 字节/Google 级 Agent 系统的架构纪律 | 纯层分离、决策渲染分离、值语义可复现、边界机器断言——这些现在已经做到了，终局只是更完善 |
| **产品形态** | 职业实训平台（像飞行模拟器、医学模拟病人） | 可考核、可复现、可评级——不是"感觉很像"，是"学员练完知道自己哪里不行" |

## 2. 终局的七层架构（从底到顶）

```
┌─────────────────────────────────────────────────┐
│  ⑦ 观测与调优层：trace / AB / 参数校准 / 调试面板  │
├─────────────────────────────────────────────────┤
│  ⑥ 伦理安全层：规则 → 模型探测 → 会后审计（三层）  │
├─────────────────────────────────────────────────┤
│  ⑤ 渲染调度层：结构化意图 → 口语化 / 语音 / 语气    │
├─────────────────────────────────────────────────┤
│  ④ 记忆系统层：三级记忆 + 召回策略 + 遗忘曲线      │
├─────────────────────────────────────────────────┤
│  ③ 关系与情绪层：同盟三维 + 移情 + 情绪动态        │
├─────────────────────────────────────────────────┤
│  ② BDI 推理层：信念 / 愿望 / 意图完整循环          │
├─────────────────────────────────────────────────┤
│  ① 纯层内核：状态定义 / 纯函数算子 / 端口契约      │
└─────────────────────────────────────────────────┘
```

## 3. 每一层终局长什么样

### ① 纯层内核（现在已基本达标）

**终局形态**：
- 零 NestJS / 零网络 / 零 env / 零 prompt，有 `boundary.spec.ts` 机器断言守着
- 全部状态是值语义（readonly），演化 = 造新快照 + 整体替换，同 seed 同配置逐字同输出
- 所有外部依赖（env / logger / LLM）走端口注入，内核不读进程环境

**现在位置**：✅ 架构纪律已达标，后续只是往里填算子，不改边界。

---

### ② BDI 推理层（现在是骨架，终局是完整循环）

**现在**：事件 → delta → 状态迁移（信任/阻抗/情绪变化），意图是从状态映射出来的策略标签。

**终局形态**：完整的 PRS 推理循环——

#### 信念（Beliefs）终局

| 层级 | 现在 | 终局 |
|---|---|---|
| 核心信念 | 有结构（`CoreBelief[]`），但没有激活规则，永远是被动数据 | 核心信念有**激活条件**：什么情境下被触发、强度怎么随相关度变化；不同核心信念会驱动不同的防御模式 |
| 短期信念 | 有结构（`TemporaryBelief[]` + 置信度），但置信度不衰减、不更新 | 每轮对话后置信度动态调整（被验证 → 增强、被反驳 → 减弱），随时间自然衰减；信念之间有冲突消解 |
| 记忆信念 | 有类型（`MemoryBelief[]`），召回靠 WP2 的 openingContext | 召回是主动的——根据当前对话内容，相关的记忆被"想起来"，影响信念强度和情绪 |

#### 愿望（Desires）终局

| 层级 | 现在 | 终局 |
|---|---|---|
| 底层愿望 | 有结构（`UnderlyingDesire[]` + 权重），但只是被动参数 | 底层愿望（被理解、被接纳、安全、自主……）是稳定的人格底色，**主动驱动**情境愿望的生成和权重调整 |
| 情境愿望 | 有结构（`SituationalDesire[]` + 优先级），但现在基本是固定模板 | 每轮根据当前情境 + 底层愿望，**生成**这一轮的具体诉求（"我想知道他是不是真的理解我" vs "我不想再聊这个话题了"）；多个愿望冲突时按优先级排序 |

#### 意图（Intention）终局

| 现在 | 终局 |
|---|---|
| 从状态 → 规则映射出一个行为策略标签（简单回应 / 探索想法 / 回避抵抗……） | 多个可能的行为策略之间做**权衡**：这个场景下，来访者是更倾向于回避还是试探？不同人格/不同关系阶段，权重不同；意图是"选出来的"不是"映射出来的" |

**一句话**：现在是"状态决定反应"，终局是"信念-愿望驱动推理，推理产生意图"——更像真人的内心过程，不是条件反射。

---

### ③ 关系与情绪层（现在有雏形，终局是完整动态系统）

**关系系统终局**：
- **咨询同盟三维**（trust / safety / bond）—— 现在已拆成独立维度 ✅
  - 终局：每个维度都有完整的建立/维持/破裂/修复曲线，不同依恋类型的曲线形状不同
  - 有**阶段模型**：开场试探 → 初步信任 → 深度袒露 → 同盟巩固，不是一条直线涨上去
- **移情**（正/负/依赖三态）—— 现在有结构 ✅
  - 终局：移情会被咨询师的特定行为**触发**（不是随便漂的），有形成→强化→修通的过程
- **反移情识别**：知道"来访者现在这个反应，触发了咨询师这边的什么感受"（实训用，不是仿真用）

**情绪系统终局**：
- 现在：离散标签（neutral/sad/anxious/angry...）+ 效价/唤醒
- 终局：
  - 情绪不是被动记录的状态，是**主动影响认知和行为**的变量（焦虑高 → 回避倾向增强、信任增长变慢）
  - 情绪有**传导性**：一个事件带来的情绪，会影响接下来几轮的解读倾向（情绪一致性偏差）
  - 情绪粒度细化：不是"焦虑"，是"被评判的焦虑" vs "失控的焦虑" vs "被抛弃的焦虑"

---

### ④ 记忆系统层（现在三级结构有了，终局是完整闭环）

**现在**：WORKING（8轮滑窗）/ SHORT_TERM（WP37 滚动摘要）/ LONG_TERM（WP2 Qdrant 召回）—— 骨架立住了。

**终局形态**：

| 能力 | 现在 | 终局 |
|---|---|---|
| 工作记忆 | 最近 8 轮咨询师发言（WP37 补了来访者侧） | 完整的对话上下文 + 注意焦点（什么被注意到、什么被忽略） |
| 会话记忆 | 滚动摘要（WP37）+ 最终摘要（WP12） | 摘要有**层次**：核心议题、关键事件、情绪转折点，不是一坨文字；跨会话的会话衔接是自然的"上次聊到哪了" |
| 长时记忆 | Qdrant 向量召回（WP2） | 召回有**策略**：Top-K 截断、时间衰减加权、相似记忆冲突消解；重要性高的记忆更容易被想起；有遗忘曲线（不重要的慢慢淡出） |
| 记忆提取偏差 | 无 | 有**情绪一致性偏差**：焦虑状态下更容易想起负面记忆；有**确认偏差**：现有信念会筛选被想起的记忆 |

---

### ⑤ 渲染调度层（现在是基础版，终局是高真实感）

**现在**：结构化意图 → LLM 渲染成口语 → TTS 发声。

**终局形态**：
- **阻抗-表达映射**：高阻抗 → 短句、浅内容、语气硬；低阻抗 → 自然倾诉、细节丰富
- **表达层随机**：同样的意图，每次说出来的话不一样（措辞/句长/停顿有随机，但意图一致）
- **非语言元素**：语气词、叹气、停顿、语速变化，都由 BDI 状态驱动
- **情绪粒度**：不是"平静" vs "低落"，是更细颗粒的情绪表达
- **人设一致性**：不管聊多久，这个角色的说话风格、用词习惯不会漂移

**关键原则不变**：渲染层负责"怎么说"，决策层负责"说什么"——这个边界永远不突破。

---

### ⑥ 伦理安全层（现在是规则+探测，终局是三层防护）

**现在**：规则禁言 + PsyGUARD-RoBERTa 风险探测。

**终局形态**：
1. **输入侧**：咨询师输入的危机语言 → 实时探测 + 分级响应（提示/阻断/转介）
2. **输出侧**：AI 来访的输出也过校验（不能说出危险指导、不能主动诱导自伤）
3. **会后审计**：整场对话的伦理标签全部留痕，督导可回溯；高风险场次自动标记重点复盘
4. **边界清晰**：安全是"兜底"，不是"束缚"——正常咨询对话不能被误判阻断

---

### ⑦ 观测与调优层（现在有日志，终局是完整工具链）

**现在**：Prometheus 指标 + 日志 + delta cap observer。

**终局形态**：
- **调试面板**：每轮对话展开 → 看到 BDI 状态变了多少、触发了什么事件、prompt 长什么样、delta cap 砍了多少
- **trace 系统**：整场会话的完整 trace，可回放、可对比（两个不同角色同一场景的差异）
- **AB 实验**：参数改了 A/B 两组，对比效果差异
- **参数校准工具**：心理咨询师可以直观地调"信任增长速率"这类参数，不用改代码
- **质量评估**：自动输出这场仿真的质量分（真实感 / 一致性 / 临床合理性）

## 5. 什么是"专家级"，什么是"次专家级"

### 专家级（终局目标）

- 心理咨询师盲测：分不出是 AI 还是真人来访
- 专业督导评价：这个仿真的临床反应是"合理的"，可以用来训练
- 可考核：同一场景不同学员来练，AI 来访的反应是一致的、可评分的
- 可扩展：加一个新角色（新依恋类型、新核心信念组合）不用写代码，配置就行

### 次专家级（商业化可接受的底线）

- **核心场景真实感够**：常见的咨询对话（焦虑、抑郁、关系问题）仿真出来，学员觉得"像那么回事"
- **关键临床构念有体现**：阻抗、同盟、移情不是 prompt 里写的，是真的状态在驱动
- **可调试可校准**：有基本的调试面板，心理咨询师能参与调参
- **安全兜底到位**：危机场景不会出幺蛾子

**我们的路线**：先到次专家级（Phase2 结束），再往专家级迭代（Phase3+）。

---

## 6. 永远不做的事（防跑偏）

1. **不做"更聪明的聊天机器人"**——我们做的是训练工具，不是陪伴产品
2. **不让模型回写状态**——BDI 状态只能由纯函数算子迁移，LLM 只负责渲染口语
3. **不在内核里塞 prompt / 网络 / env**——纯层边界永远不破
4. **不追求一步到位的完整 BDI**——先立住骨架，再慢慢填血肉，需求驱动不堆理论
5. **不拿"学术完整性"当借口过度设计**——没有实训场景的理论，不提前编码
