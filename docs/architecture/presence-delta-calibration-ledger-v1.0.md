## 2. 幅度实测（13 场语料 / 157 neutral 轮）

基线事实：语料内 `holding_present` 命中 117 轮、`cold_absent` 仅 1 轮。1× 即内核种子倍数。

| 倍数 | 平均 safety 增益                    | 平均 bond 增益 | 触顶场次 | cap 触发 |
| ---- | ----------------------------------- | -------------- | -------- | -------- |
| 0×   | 0（零增益基线不漂）                 | 0              | 0        | 0        |
| 1×   | +0.0358                             | +0.0178        | 0        | 0        |
| 2×   | 约 +0.0716（达平均 +0.05 的最低档） | 约 +0.0356     | 0        | 0        |
| 4×   | 约 +0.1432（达平均 +0.10 的最低档） | 约 +0.0712     | 0        | 0        |
| 8×   | +0.2868                             | +0.1428        | 0        | 0        |

- 批次总计（1×，13 场求和）：safety +0.4660 / bond +0.2320，与 AF-418 的逐字稿完全一致。
- 结论：**cap 不是瓶颈；瓶颈是幅度本身与来访体感**。要把单场平均增益抬到 +0.05 需要 2×，抬到 +0.10 需要 4×；8× 都不触顶，说明还可以继续往上调，但体感风险同步上升。
- 数据出处：AF-421（幅度扫描）、AF-422（cap 感知重放，以 `cap(real+presence) − cap(real)` 精确定义「在场在 cap 下的有效贡献」）。

## 3. 结构事实：谁来产出这两类事件

这一条比数字更重要，决定了「调大 seed 有没有用」。

- **规则轨产不出**：`rule-based-classifier.ts` 的词表刻意不扩，`holding_present` / `cold_absent` 属跨轮状态判断，规则轨只消费「咨询师本轮文本」，不伪造。
- **模型轨能产出**：`model-event-classifier.ts` 的分类提示词里明确列了两类 kind 的判定口径（先判行为标签；无行为标签时才在 neutral / holding / cold 三者里互斥选一），并带 `neutralStreak` / `coldStreak` 两个连续轮数作为上下文。
- **所以**：deltas 表里种子再准，只要模型轨没开，真实对练里这两类事件就是 0 次命中，八维照旧不动 —— 这也是 zero_motion 根因审计（MiniMax 只读审计）里 R2「结构性：D-2 的在场事件在本仓没有任何一条轨能产出」的准确含义：不是没有实现，是默认链路上规则轨当值。
- **口径差异**：`DELIBERATION_RULE_ALIGNED_TAGS` 刻意不含这两类，因为它是「规则算子也会打」的标签组，影子对比要的是「规则覆盖不到多少」；把模型独有标签塞进去会把统计口径弄糊。这条决定本身没错，但文件里「两类 delta 种子是 ZERO」的旧注释已过期（AF-322 起就是非零种子），属文档漂移，待 executor 后续任务修。

## 4. 证据缺口（必须写在结论旁边）

1. **冷缺席样本几乎为零**：157 轮里 `cold_absent` 只有 1 轮。`cold_absent` 的负向幅度（trust −0.004 等）目前**没有任何批次证据支撑**，只能当占位种子。
2. **真人度未评分**：幅度调大后的临床风险（过度安抚、机械正向、把敷衍当成陪伴）无法用 cap 或增益指标把关，需要 R4/R6 真人度评分介入。
3. **A′ 真实精确率未标定**：AF-415 的 40 行抽样 CSV 仍待人工标注，标注前不能给「规则轨把该判 holding 的轮判成 neutral 的比例」的临床结论。

## 5. 后续标定要做的三件事

1. **取样**：专门构造「稳定陪伴」与「敷衍/模板化」两类剧本各 ≥ 20 场，让 `holding_present` 与 `cold_absent` 都有足够样本；当前语料 117:1 的比例不足以标定冷缺席方向。
2. **真人度评分**：在 2× / 4× 两档上跑 R4/R6 真人度，检查幅度上升是否换来体感下降；只有体感不掉，抬高倍数才有意义。
3. **临床拍板**：把「稳定在场算不算正事件」「冷缺席是否该有独立阈值」两个口径交给督导定，落进 `metric-dictionary.ts` 的正事件率口径里 —— 当前默认不纳入，是**待决**而非结论。

## 6. 复算方式

三个脚本都在仓内，全部只读、零上游计费，可直接重跑：

```powershell
node scripts/ops/quality/af418-presence-replay-calibration.mjs --dir data/debug-sessions
node scripts/ops/quality/af421-presence-amplitude-sweep.mjs --dir data/debug-sessions
node scripts/ops/quality/af422-presence-cap-aware-replay.mjs --dir data/debug-sessions
```
