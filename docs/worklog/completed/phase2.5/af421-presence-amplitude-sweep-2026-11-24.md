# AF-421 交付记录：在场 delta 幅度扫描（倍数 → 增益 → 饱和）

- 任务：AF-421（investigation，只读分析）
- 日期：2026-11-24
- 基线：`7275462bb9cc677fe5f1e96747a906a6894d401e`（AF-420 合并后的 integrate）

## 1. 为什么要这一单

AF-420 把 `ENGINE_DELTA_HOLDING_PRESENT` / `ENGINE_DELTA_COLD_ABSENT` 接进了 env，标定批次从此能改幅度，但「改到多大」没有依据：AF-418 只证明了 1×（内核种子）幅度下的末态增量（13 场 safety +0.4660 / bond +0.2320），没有倍数-增益曲线，也没说清放大到多少会先撞 clamp 或 cap。

本单给的就是这条曲线：同一份种子幅度按 0× / 0.25× / 0.5× / 1× / 2× / 4× / 8× 缩放后逐轮重放，输出每档的平均增益、触顶场次与 cap 触发轮次。

## 2. 实测结果（13 场 / 157 neutral 轮 / A′ holding 117 / cold 1）

| 倍数  | 平均 safety 增益 | 平均 bond 增益 | 触顶场次 | cap 触发轮次 |
| ----- | ---------------- | -------------- | -------- | ------------ |
| 0×    | 0.0000           | 0.0000         | 0/13     | 0            |
| 0.25× | 0.0090           | 0.0045         | 0/13     | 0            |
| 0.5×  | 0.0179           | 0.0089         | 0/13     | 0            |
| 1×    | 0.0358           | 0.0178         | 0/13     | 0            |
| 2×    | 0.0717           | 0.0357         | 0/13     | 0            |
| 4×    | 0.1434           | 0.0714         | 0/13     | 0            |
| 8×    | 0.2868           | 0.1428         | 0/13     | 0            |

1× 档的批次总增益 +0.4660 / +0.2320 与 AF-418 逐字一致（口径未漂的证明）；0× 档与「完全不叠加 presence」逐字相同（基线不漂）。

## 3. 读出来的三个结论

1. **当前种子幅度偏弱。** 1× 下平均每场只拿到 +0.036 safety（≈ 单轮 cap 预算 0.20 的 18%），稳定在场 30 轮才够 +0.10 量级；对训练体感几乎没有可辨识差异。
2. **放大到 8× 仍未触饱和。** 7 档里触顶场次保持 0/13、cap 触发轮次保持 0——增益严格线性。原因是单轮 presence delta 只有 0.002–0.004，即便 8× 也只 0.032，远低于 clamp 与 safety 上向 cap（0.20）。
3. **可达目标有明确倍数。** 要平均 +0.05 需 2×；要平均 +0.10 需 4×。给出的是「倍数区间」而不是拍脑袋单值，标定批次可以在这条曲线上直接选点。

## 5. 边界与不可当作结论的部分

- **静态反事实**：重放只把 presence delta 叠在真实轨迹上，不重算来访后续回应；它回答「同样的对话，账面上多出多少」，不回答「来访真的更安心」。
- **cap 判定是近似**：用 trace 记录的当轮 `delta` 当真实增量，未含 timing 折损与人格调节；cap 触发数为 0 只说明「近似口径下没撞」，不等于精确口径下也不会撞。
- **标签来源**：A′ 标签由规则轨窄分类器给出（AF-409），不是人工标注；精确率仍未标定（AF-415 的 40 行 CSV 待标注）。
- **只在当前 13 场数据上成立**：换批次需重跑。
