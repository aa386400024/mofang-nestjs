# AF-335 · 真人度基线分离度与阈值敏感性实测报告（2026-11-23）

## 结论先行

1. **只有 `full` 能被单一阈值与 off 完全分开。** 把 AF-333 与 AF-334 的 off 样本合并成 8 个后，焦虑可分区间 `[3.583062, 5.785124)`，回避 `[4.280156, 6.060606)`；中点阈值分别为 `4.684093` / `5.170381`，在现有样本上都是 `TP=8 / FP=0 / TN=8 / FN=0`。
2. **`minimal` 与 `tightened` 与 off 不可分。** 两者都存在低于 off 最大值、甚至低于 off 中位数的样本，任何能拒绝它们的阈值都会把部分 off 判成过量。这不是阈值没调好，而是分布重叠。
3. **一个跨人设的统一阈值只能落在 `[4.280156, 5.785124)`。** 下界由回避 off 的最大值 `4.280156` 决定，上界由焦虑 full 的最小值 `5.785124` 决定；中点约 `5.032640`。在该点上 16 个 off 全部判负、16 个 full 全部判正，但这只是当前 8+8 样本的巧合，不是稳健阈值。
4. **gate 只能作为“拒绝 full”的过量报警，不能作为“认证 active”的开关。** 因为 `minimal` / `tightened` 都落在 off 的分布范围内，gate 通过不代表候选安全；候选是否可上线必须另走 allowlist。
5. **8 个 off 样本仍不足。** 下界被单个回避 off 样本 `4.280156` 顶到接近 full 下界；再多几个 5+ 的 off 样本，full 的“完全可分”就会消失。需要 ≥16–20 重复才能谈稳定分离区间。
6. **生产继续 `off`；不调 `humanization-v1`；不启用 active 候选。**

## 统一阈值与分人设阈值

| 方案 | 区间 | 中点 | 适用 |
| --- | --- | --- | --- |
| 跨人设统一 | `[4.280156, 5.785124)` | `5.032640` | 16 off 全部判负、16 full 全部判正 |
| 焦虑单独 | `[3.583062, 5.785124)` | `4.684093` | 更早拦截焦虑 full |
| 回避单独 | `[4.280156, 6.060606)` | `5.170381` | 下界被回避 off 抬高 |

统一阈值 `5.03` 低于所有 full 样本、高于所有 off 样本，因此仍能全拦全放；反过来，任何低于 `4.280156` 的统一阈值都会把回避 off 的 `4.280156` 判成过量。若按人设分开，焦虑可以更早报警（`4.68`），回避不能低于 `4.28`。

## 归因

### `full` 与 off 的分离是“当前样本的分离”

`full` 的 16 个样本最低 `5.785124`，off 的 16 个样本最高 `4.280156`；这给出 1.5 个点的空档。但 off 的分布仍有长尾：焦虑 `3.583062`、回避 `4.280156` 已经接近 full 下界。只要下一批 off 出现一个 `5.0` 的样本，完全可分就不成立。8+8 样本不足以证明“full 永远高于 off”。

### `minimal` / `tightened` 与 off 的重叠是结构性的

`minimal` 是“配额 + 稳定层”，`tightened` 是收紧候选；它们的低值样本来自模型自身的正常表达，不是异常。把它们当作“应被 gate 拒绝”的候选，等价于要求 gate 能识别“哪一轮的口语事件是 prompt 造成的、哪一轮是模型自然生成的”，单一密度阈值做不到。

### 阈值敏感性不是调参问题

在当前数据上，把 `humanization-v1` 的 `2.50` 改成 `3.5`、`4.5`、`5.0` 都能改变混淆矩阵，但没有一个阈值能同时做到：接受全部 off、拒绝全部 full、拒绝全部 minimal/tightened。三者不可兼得。继续调阈值只会把错误从假阳性搬到假阴性。

## 决策与建议

- **生产保持 `off`**，不调 `humanization-v1` 的 `2.50`。
- **如需过量报警**，可另设“full-only 报警线”：统一 `5.03`，或按人设 `4.68 / 5.17`；它只回答“这批是不是 full”，不回答“候选能不能上线”。
- **候选上线走 allowlist**：`minimal` / `tightened` 必须单独评审，不靠密度 gate 自动放行。
- **下一步：**
  1. off 重复数扩到 ≥16–20，先确认 `full` 与 off 是否仍完全可分；
  2. 事件层与形态层拆到句子级，找最小可保留子集；
  3. 若要设统一阈值，先固定“假阳性预算”，再报告对应的 full 检出率，不要先定阈值后解释。

## 边界

- 合成人设、合成台词；不写库、不启服务、不改生产 prompt、不调阈值。
- 所有区间都是 8+8（tightened 4+8）样本的工程观测，不是置信区间；不能外推全部来访者。
- 判据是工程种子，不是临床真人度量表；不宣称疗效或临床真人度。
