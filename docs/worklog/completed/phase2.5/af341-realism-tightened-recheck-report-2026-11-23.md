## 5. 结论

1. **`tightened` 是稳定的最低密度候选**：均值 2.79 / 3.02，3/8 与 4/8 在窗；比 AF-335 的 4 次更可信。
2. **但它与 off 完全不可分**。把它当“真人度达标”的候选，等于承认评测无法区分它和 off。
3. **`humanization-v1` 的密度窗口与“可分离”目标不能同时满足**。继续在密度上找“既进窗又分得开”的臂，是结构性死路。
4. **下一步不应再加臂，而应换判据**。密度只能做“事件量”监控；要做真人与否的判断，需要事件类型组成（AF-338 剖面）、人设声音（trailoff / 半截话占比）或外部标注，而不是密度阈值。
5. **工程口径建议**：full 家族保留分人设报警线（统一中点 `4.943817`，只报警不认证）；`tightened` 作为“低事件量可读候选”，只用于降低疲劳，不用于认证。
