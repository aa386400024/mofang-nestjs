1. **归档不存命中词（matchedTerms）** → 双标签轮只能确定「两类同时出现」，**不能逐轮证明是子串重叠所致** → 重叠对贡献按**上界**报告（§3 偏差 2）；
2. **不做逐事件分量分解** —— 归档 delta 经角色倍率 / 人格调制 / capTurnDelta 折损 / 时序权重处理，脚本不反推单事件分量（任务单 §3.3）；
3. **样本不足规则**：分组轮数 < `--min-samples`（本次 20）即标「样本不足 · 不出结论」，不强行给点值；
4. **退化轮不做特殊剔除** —— 归档「degraded」= 渲染降级，规则事件仍推进状态（与 I-11 单结论一致），故退化轮保留在分组内并单列退化分层计数；
5. **模式分层不可用** —— 归档场次不在现有批次血缘里（§3 偏差 4）；
6. **归档时点** —— 归档快照早于 S-1 / D-2 落地，事件 kind 集合与词表口径与当前版本存在时点差；本单只用归档里已落库的 kind 标签，不反推当前分类器行为；
7. **本单不做消歧判断** —— 「是否消歧 / 改词还是改分类器 / 是否修订 D-1 基线 spec」属取证结论 + 用户拍板后的另案实现单（任务单 §1.2.5）。
