# AF-331 · 来访者真人度 prompt 减层与候选收紧实测报告（2026-11-23）

## 结论先行

1. **`minimal`（只留配额 + 稳定层，删掉形态层和事件层）是七个分支里最接近 off 的。** 焦虑密度 `3.211870`、回避 `2.684685`，相对各自 off 为 `-0.038985` / `-0.531991`；但没有任何分支在两个人设、两次重复上稳定通过 `humanization-v1`。
2. **事件层是最大放大器。** `full → no-event` 让焦虑密度从 `7.625786` 降到 `4.762038`（`-2.863748`），回避从 `8.050009` 降到 `6.000600`（`-2.049409`）；`no-event` 仍保留形态与配额，密度依旧超上限。
3. **形态层不是唯一原因，但在回避人设上很重。** 删形态层让回避密度从 `8.050009` 降到 `6.810966`（`-1.239043`），焦虑反而从 `7.625786` 升到 `7.915154`（`+0.289368`）。
4. **收紧候选没有达到可上线标准。** 焦虑 `2.952407`（`failed ×2`），回避 `4.104616`（`failed ×2`）；回避比 `minimal` 更差，说明“整场最多两次”的措辞没有被稳定遵守。
5. **off 自身也可能超密度上限。** 本单 off 焦虑 `3.250856`、回避 `3.216676`，都高于 `2.50`；AF-330 同人设 off 是 `1.732229` / `1.587401`。两轮重复 × 6 轮的采样方差足以把基线推出窗口，`humanization-v1` 的密度门槛需要长会话或配对中位数校准，不能拿单批结果当稳定基线。
6. **生产继续 off。** 没有任何候选通过；`minimal` 只能说明“删掉形态与事件层后回到基线附近”，不能说明“已经有可部署的 active”。

## 归因

### 事件层

`no-event` 只删掉事件层一行，保留形态、配额和所有稳定层，密度却下降最多：焦虑 `-2.863748`、回避 `-2.049409`。这说明事件层的四类候选清单和节奏条件（“停顿一次就够”“改口放在句缝”）是主要放大器，不只是配额数值。

### 形态层

`no-shape` 在回避人设上把密度从 `8.050009` 降到 `6.810966`，但焦虑人设反而升到 `7.915154`。原因可能是焦虑的形态行被删除后，模型转向事件层和配额自行补事件；回避的形态行“先挡一下、这个……”本身就在制造每轮 pause，删掉后 pause 从 `6` 降到 `2`。因此形态层对两人的作用不对称，不能一刀切认定“形态层是根因”。

### 配额层

`no-quota` 在焦虑只降 `0.193503`，在回避降 `1.363802`；配额不是主要贡献，但删掉后模型并没有更少事件，说明模型更多跟随形态与事件候选，而不是跟随数值上限。

### minimal 与 tightened

`minimal` 只留配额 + 稳定层，焦虑回到 off 附近（`-0.038985`），回避甚至低于 off（`-0.531991`）；但它仍不是合格候选：回避 `2.684685` 仍高于 `2.50`，焦虑一次 pass 一次 fail。

`tightened` 虽然把密度压到焦虑 `2.952407`、回避 `4.104616`，但回避比 `minimal` 高 `1.419931`，且两人设都是 `failed ×2`。这说明“整场最多两次、本轮最多一次”这类跨轮计数没有被稳定执行；靠自然语言让模型记住整场预算并不可靠。

### off 基线

本单 off 密度 `3.250856` / `3.216676`，均高于 `2.50`；AF-330 同人设 off 是 `1.732229` / `1.587401`。同 prompt、同模型、同 6 轮，两个任务相差近一倍，说明 6 轮短文本的密度指标方差很大。`humanization-v1` 的 `density_per100` 门槛在短会话上不能当作稳定判据；用它判断 prompt 好坏之前，必须先解决基线抖动。

## 决策

- **生产保持 off，不启用任何候选。** `minimal` 只是回到基线附近，`tightened` 不达标。
- **不要继续加配额或放宽门槛。** 事件层和形态层是主要贡献；应先减少这两层的逐轮命令，再谈配额。
- **下一步优先级：**
  1. 把 `humanization-v1` 的短会话密度判定改成配对中位数或延长到 ≥12 轮，先把 off 基线稳定下来；
  2. 只保留 `minimal` 的结构做生产候选，去掉形态层与事件层，观察 12 轮以上是否稳定；
  3. 若要保留形态/事件，应改为低频事件池（整场 1-2 次）而不是每轮指令，并用可验证的计数约束，不能只靠“整场最多两次”的自然语言。

## 边界

- 合成人设、合成咨询师台词；不写库、不启服务、不改生产 prompt、不切 `RENDER_REALISM_MODE`。
- 2 人设 × 2 重复只够看到方向与方差，不够做统计显著性；不能外推到全部来访者。
- 所有判据是工程种子，不是临床真人度量表；不宣称疗效或临床真人度。
