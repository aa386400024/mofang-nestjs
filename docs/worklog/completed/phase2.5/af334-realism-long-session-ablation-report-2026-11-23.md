# AF-334 · 真人度 12 轮长会话层归因消融实测报告（2026-11-23）

## 结论先行

1. **长会话里没有单一“元凶层”，事件层是最大单项但拆掉仍不够。** 焦虑 `full` 中位数 `8.011380`，拆事件层 `no-event` 降到 `4.562399`（−3.45），拆形态层 `no-shape` 降到 `5.812457`（−2.20），拆配额层 `no-quota` 仍有 `6.921429`（−1.09）。回避同样：`7.065368 → 6.079105 / 5.230769 / 7.195512`。
2. **只删配额层几乎不降密度。** `no-quota` 焦虑 `6.921429`、回避 `7.195512`，与 `full` 同档，说明配额不是主要放大器；事件层与形态层叠加才会把密度推到 7–8。
3. **同时删事件 + 形态的 `minimal` 是当前最接近基线的候选，但仍未进入窗口。** 焦虑 `3.298872`（`1/4`）、回避 `2.577095`（`2/4`）；两人设中位数都高于 `2.50`。
4. **`tightened` 在 12 轮上不稳定。** 焦虑 `2.836195`（`0/4`）、回避 `2.995731`（`0/4`）；焦虑看似接近，但 4 个样本全部高于上限，回避反而被抬高。
5. **off 基线自身仍在 2.0–4.3 摆动。** 本批 4 次重复：焦虑 off `2.066116 – 3.583062`、中位数 `2.615241`、`2/4` 在窗口；回避 off `2.118644 – 4.280156`、中位数 `3.356395`、`1/4`。与 AF-333 的 4 次重复合并成 8 个样本后，焦虑 off 中位数约 `2.607`、回避约 `3.115`，仍都在窗口外。
6. **生产继续 `off`。** `full` / `no-quota` 稳定过量；`minimal` / `tightened` 都未证明能把两人设带回窗口。

## 归因

### 事件层：最大单项，但不是唯一放大器

`full → no-event` 是单项删除里降幅最大的：焦虑 `8.011380 → 4.562399`（−3.45，−43%），回避 `7.065368 → 6.079105`（−0.99，−14%）。但两人设都仍远高于 `2.50`，说明事件层之外还有其它持续源。

### 形态层：对回避贡献更大

`full → no-shape`：焦虑 −2.20（−27%），回避 −1.83（−26%）。与事件层联合删掉（`minimal`）后，回避降到 `2.577095`、焦虑 `3.298872`，说明两层有叠加效应，但焦虑的基础表达仍会超线。

### 配额层：拆掉几乎不降

`no-quota` 焦虑 `6.921429`、回避 `7.195512`，与 `full` 基本同档。因为事件层与形态层仍在，配额只是“额外约束”，不是密度主因；反过来说，只收紧配额不会解决过量。

### `minimal` 仍不是可靠修复

焦虑 `minimal` 中位数 `3.298872` 高于 off `2.615241`，`1/4` 在窗口；回避 `2.577095` 虽低于本批 off `3.356395`，仍高于 `2.50`，`2/4`。它比 `full` 好，但还不能作为 active 候选。

### `tightened` 在 12 轮上不稳定

焦虑中位数 `2.836195` 接近上限，但 4 个样本全部高于 `2.50`；回避 `2.995731`，`0/4`，且均值 `3.283580` 被一个 `4.285714` 的样本抬高。短会话（AF-331）里 tightened 焦虑 `2.952407`、回避 `4.104616`，长会话没有改变其不可用结论。

### off 基线仍然不可作为单批 gate

AF-334 的 off 焦虑 `2.615241`、回避 `3.356395`，与 AF-333 的 `2.607085`、`2.344401` 并不一致；合并 8 个样本后焦虑约 `2.607`、回避约 `3.115`，都高于 `2.50`。同一 prompt 的 off 在不同批次能差 1–2 个密度点，单批均值或单批判定不可信。

## 决策

- **生产保持 `off`。** `full` 与 `no-quota` 稳定过量；`minimal` / `tightened` 都没有把两人设带回窗口。
- **不调 `humanization-v1` 阈值。** 12 轮的 off 中位数仍在 `2.6 / 3.1`，问题不是阈值数字。
- **不启用任何 active 候选。** 事件层与形态层同时存在时，生产块会稳定每轮附加事件；只删一层不够。
- **下一步候选：**
  1. 把事件层与形态层的“最小可保留子集”继续拆到句子级，确认哪几条规则必须保留；
  2. 把 off 基线扩到 ≥8 重复并按人设分开，先得到稳定基线区间，再谈 gate；
  3. 若要保留 `minimal`，只作为中间态，不作为生产候选；`full` 永不启用。

## 边界

- 合成人设、合成咨询师台词；不写库、不启服务、不改生产 prompt、不切 `RENDER_REALISM_MODE`、不调阈值。
- 4 次重复、2 合成人设仍不足统计显著性；合并 8 个 off 样本只是方向性基线，不是置信区间。
- 所有判据是工程种子，不是临床真人度量表；不宣称疗效或临床真人度。
