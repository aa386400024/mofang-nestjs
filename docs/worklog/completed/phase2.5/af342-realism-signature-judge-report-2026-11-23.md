# AF-342 报告 · 真人度签名判据 v1 与零调用回验

- 日期：2026-11-23
- 基线：`e91497412a3f0c6d1245f49ef206e4df75229b47`（AF-341 合并后）
- 模型调用：**0 次**
- 样本：7 个臂 × 2 人设 × 8 次 = 112 个已归档 12 轮会话样本
- 性质：工程结构判据，不是临床真人度结论

## 1. 判据设计

`realism-signature-judge-v1` 用两个轴代替单一密度窗口：

**轴一：人设签名是否保留**

| 人设 | 签名事件 | 阈值 | 校准依据 |
| --- | --- | --- | --- |
| 焦虑依恋 | 改口 `repair` | `repair/turn ≥ 0.05` | off 16 次 repair 恒为 0，留 1 次/20 轮余量 |
| 回避依恋 | 接近每轮停顿 `pause` | `pause/turn ≥ 0.9` | off 16 次最高 `0.666667`，留 0.233 余量 |
| 回避依恋 | 半截话 `trailoff` | `trailoff/turn ≥ 0.15` | off 16 次最高 `0.083333`，留 0.067 余量 |

**轴二：密度是否过载**

`density_per100 > 4.943817` 记过载。这个值沿用 AF-335/AF-337 的 full-only 报警线统一点中，只作“过载提示”，不作真人认证。

**三态输出**

| 签名 | 密度 | 判定 | 含义 |
| --- | --- | --- | --- |
| 未保留 | 任意 | `off-like` | 结构上退化成对照，不能称为真人化 |
| 保留 | ≤ 上限 | `humanized` | 保住了人设特征且未过载 |
| 保留 | > 上限 | `overloaded` | 保住了人设特征但话轮过重 |

**关键校验**

- off 误报：`0/16`。所有对照样本都判 `off-like`。
- full 签名覆盖：`16/16 = 1.000`。正向对照没有漏判。
- minimal / typed-noshape：`32/32` 判 `off-like`，与“删掉结构层就回退”的设计一致。
- tightened 焦虑：`8/8 humanized`；tightened 回避：`8/8 off-like`。同一个臂在人设上分裂，说明判据抓的不是密度，而是“回避的每轮停顿/半截话是否还在”。
- shape-capped 回避有 1 个 `off-like`（密度 `5.925926`、签名强度 `0.648`，pause 7 次 + trailoff 1 次），属于边界样本，没有掩盖。

## 3. 这个判据解决了什么

1. **不再要求“密度进窗”才能算真人化。** 焦虑 tightened 密度 `2.79`、与 off 重叠，但签名保留，判 `humanized`；AF-341 的“密度与分离性互斥”在这里被绕开。
2. **能诚实判负。** 回避 tightened 密度也低、看起来“轻”，但每轮停顿和半截话都丢了，判 `off-like`，不再把“轻”误当成“真人”。
3. **完全可解释。** 每个判定都能给出 `persona`、签名强度、阈值、密度与上限，没有黑箱分数。
4. **零调用可复跑。** 112 个样本全部来自已归档 rep 文件，判据改动后可以立刻重跑，不需要再烧 API。

## 4. 不能解决的问题（必须写清）

- 判据是**结构代理**，不是“读起来像真人”的临床判断；没有真人咨询师或外部标注。
- 阈值来自 16 个 off 样本，样本量小；换模型、换 prompt 家族、换语种都要重新校准。
- 焦虑“出现一次改口”就算签名保留，偏宽松；可能把偶发噪声当成特征保留。需要后续用 32 样本重估阈值。
- `humanized` 只表示“签名在、密度不过载”，不表示质量高；`overloaded` 也不表示一定不自然，只表示话轮偏重。
- 密度上限 `4.943817` 是 full-only 报警线，不是产品验收线；产品要不要更严，是业务决策。

## 5. 建议的落地方式

1. **影子模式先跑**：在评测流水线里同时算 `humanization-v1` 与签名判据，只记录不阻断，积累 2–4 周对照。
2. **报警与认证分离**：密度只做“过载报警”；签名判据做“是否退化”的判断；两者都不单独宣称临床真人度。
3. **阈值再校准**：等 off 样本到 32、每个候选到 16 次重复，重估三个人设阈值；当前常量集中在模块顶部，替换成本低。
4. **接入点**：判据输入是会话级 `turns + density + 六类计数`，与现有 `BatchMetricsV1` 聚合层同构；下一步只需在聚合后调用，不需要改渲染链。

## 6. 边界

- 单模型（豆包 Seed Character）、合成人设、12 轮 long 会话。
- 无真实咨询师在环，无人工听感评估。
- 本报告不构成临床有效性、疗效或诊断结论。
