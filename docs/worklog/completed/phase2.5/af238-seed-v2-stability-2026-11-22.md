# AF-238 · seed-v2 三采样稳定性复核

- 任务：`AF-238`（`phase2.5-orchestration-closed-loop`）

## 结论

**合作度维度稳定，seed-v2 三次采样均显著低于 seed-v1。**

| 轮次 | C 合作指数 | E 合作指数 |
| --- | --- | --- |
| r1 | 0.243056 | 0.097222 |
| r2 | 0.222222 | 0.090278 |
| r3 | 0.180556 | 0.111111 |
| 均值 | 0.215278 | 0.099537 |
| 极差 | 0.0625 | 0.020833 |

E 三轮全部 ≤ `0.12`，C 三轮全部 ≥ `0.18`。E 的盲评均分 `3.875 / 4 / 4.083333`，均值 `3.986111`；C `3.833333 / 4.045455 / 3.833333`，均值 `3.90404`。E 在合作度和均分两个核心维度都稳定优于 C。

但三次运行的硬门槛不是全过：r2 中 C 出现 `plot` 与 `tag-error` 硬失败，E 出现 `first-token-p95` 硬失败。进一步核对发现 **E 的 r2 硬失败是指标聚合缺陷，不是模型延迟**：`mergeMetrics` 把 12 场各自的 P95 取最大值作为整体 P95，得到 `2981ms`；按 144 轮全局样本重算实际 P95 为 `900ms`。同一缺陷也把 r1 的 E 从全局 `876ms` 抬到 `1073ms`、C 从 `782ms` 抬到 `975ms`。该缺陷已登记 AF-239 修复，不在本任务改代码。

结论：**seed-v2 的合作度压制稳定，可继续作为 prompt V2 候选；硬门槛的延迟项需先修指标聚合再重判。seed-v1 的格式失稳（r2 plot/tag）不具备竞争力。**

## r2 具体失败

- C：`plot-zero` 未过（1 次剧情化推进）、`tag-error-rate` 未过（`0.013889`，2 个非法标记）。
- E：报告 `firstTokenP95Ms = 2981`，因为 12 场中两场出现单轮 `2766ms` / `2981ms`，取最大值后覆盖整体。全局 144 轮 P95 是 `900ms`。
