# AF-336 · 真人度 off 基线扩样与 full 分离复核实测报告（2026-11-23）

## 结论先行

1. **16 个 off 样本下，full 仍与 off 完全可分。** 焦虑 off 最大值 `4.150943`、full 最小值 `5.785124`，可分区间 `[4.150943, 5.785124)`；回避 off 最大值 `4.280156`、full 最小值 `6.060606`，区间 `[4.280156, 6.060606)`。中点阈值 `4.968033` / `5.170381`。
2. **但 off 基线本身更差了。** 合并 16 个样本后，焦虑中位数 `2.729458`（`5/16` 在窗口）、回避 `3.147257`（`4/16` 在窗口）；两人设中位数都高于 `humanization-v1` 的 `2.50`，且只有约 1/4–1/3 的样本在窗口内。
3. **8 个新 off 样本把焦虑上界从 `3.583062` 推高到 `4.150943`，空档只剩 1.63。** 回避上界仍由旧样本 `4.280156` 决定。再多几个 4.5–5.0 的 off 样本，full 与 off 的“完全可分”就会消失。
4. **统一阈值仍只能落在 `[4.280156, 5.785124)`，中点约 `5.032640`。** 下界由回避 off 最大值决定，上界由焦虑 full 最小值决定；这个阈值高于所有 16 个 off、低于所有 8 个 full，但依然是 24 个样本的巧合，不是稳定门槛。
5. **`minimal` / `tightened` 仍然不可分。** 扩样只增加 off，没有改变它们与 off 的结构性重叠；任何拒绝它们的阈值仍会误伤 off。
6. **生产继续 `off`；不调阈值；不启用 active 候选。**

## 归因

### 扩样证明的是“当前仍可分”，不是“稳定可分”

16 个 off 的最大值 `4.280156` 仍低于 8 个 full 的最小值 `5.785124`，空档约 1.5。焦虑上界被新样本推到 `4.150943`，离 full 下界只剩 1.63；这已经是 24 个样本里最接近的一对。只要再来一个 `5.0+` 的 off 样本，焦虑的完全可分就消失。

### off 基线中位数仍在窗口外

焦虑 `2.729458`、回避 `3.147257`；16 个样本里只有 `5/16` 与 `4/16` 在 `[0.20, 2.50]` 内。即使把 `humanization-v1` 的窗口从 `2.50` 放宽到 `3.20`，回避仍有约一半样本在窗口外。基线不稳定不是采样太少一个原因，模型对 off 的默认表达本身就在 2–4 之间波动。

### full-only 报警线可行，active 认证仍不可行

用 `[4.280156, 5.785124)` 的统一阈值可以 0 误伤地拒绝当前所有 full，但同一阈值下 minimal / tightened 也全部通过；这再次说明 gate 只能当“full 报警”，不能当“候选认证”。候选必须走 allowlist。

## 决策

- **生产保持 `off`。**
- **不调 `humanization-v1` 阈值。**
- **不启用 `full` / `minimal` / `tightened`。**
- **如果要做 full-only 报警**，当前可用的统一线是 `[4.280156, 5.785124)`，中点 `5.032640`；按人设是焦虑 `4.968033`、回避 `5.170381`。但必须标注“24 样本、非稳定门槛”。
- **下一步：**
  1. 若还要扩样，优先补 full/minimal，而不是只补 off；否则 off 上界继续上升、full 样本不动，分离会被单边挤压；
  2. 做句子级事件归因，找事件层/形态层的最小可保留子集；
  3. 候选上线走 allowlist，不靠密度 gate 自动放行。

## 边界

- 合成人设、合成台词；不写库、不启服务、不改生产 prompt、不切 `RENDER_REALISM_MODE`、不调阈值。
- 16 个 off + 8 个 full + 8 个 minimal + 4 个 tightened 仍是小样本，不是置信区间。
- 所有判据是工程种子，不是临床真人度量表；不宣称疗效或临床真人度。
