## 结论先行

1. **单纯按类型收紧事件层，压不住形态层。** `typed` 焦虑密度中位数 `5.045884`（`0/8` 在窗口）、回避 `6.153846`（`0/8`），仍远高于 off 的 `2.729458` / `3.147257`。
2. **焦虑 typed 的 `repair` 从 full 的 `0.6875` 降到 `0.3750`，但没有归零。** 事件层写了“不要改口”，`repair` 仍每轮 `0.375`；说明形态层的“说出口后改一次口”在持续驱动改口。
3. **回避 typed 的 `pause` 仍是每轮 `1.0000`，与 full 完全一样。** 事件层写了“不要每轮都停顿”，但形态层的“这个……我不太想说”本身就每轮带停顿；禁令没有生效。
4. **去掉形态层后，密度回到 off，候选的增量也一起消失。** `typed-noshape` 焦虑中位数 `2.835170`（`2/8`）、回避 `2.925578`（`2/8`），`repair` 两人设都为 `0`，事件剖面与 off 基本同词表。
5. **所以形态层是事件的主驱动，不是事件层。** 保留形态层 → 事件压不下来；删除形态层 → 回到 off。继续在事件层做减法是死路。
6. **生产继续 `off`；`typed` / `typed-noshape` 都不作为候选。**

## 归因

### 形态层是“每轮事件”的发动机

焦虑形态层原文是“说出口后改一次口”，回避是“这个……我不太想说”。这两句本身就是每轮可执行的动作指令：焦虑每轮至少一个改口，回避每轮至少一个停顿。事件层写“不要改口 / 不要每轮停顿”，优先级低于形态层，模型按形态层执行。

### 事件层减配只减掉了“第二、第三个事件”

焦虑 full 每轮 `2.02` 个事件，typed 降到 `1.04`：减掉的是 repair 的第二层与部分 filler，但形态层保底的一个改口还在。回避 full 与 typed 的 pause 都是 `1.0`，事件层没有任何效果，因为 full 的 pause 本来就只由形态层提供，`trailoff 0.2083` 被 typed 删掉后密度从 `6.98` 降到 `6.15`。

### 去形态后回到 off，说明增量与形态层绑定

typed-noshape 的焦虑事件 `53`、off `64`；回避 `38`、off `55`。词表几乎相同：焦虑 filler/pause 为主、repair 为 0；回避 pause 为主。密度也回到 `2.8–3.0`，落在 off 的分布里。**这说明当前 prompt 的真人度增量不是“事件层加出来的”，是“形态层每轮执行”带出来的；删掉形态层就等于回到 off。**

### 破局点不在事件层

继续在事件层做“少加一点”的实验没有意义：保留形态层就压不到窗口，删掉形态层就回到 off。下一步必须改形态层的语义：
1. 把“每轮执行”改成“整场最多 N 次、按状态触发”；
2. 或者把形态层拆成“高频低强度”和“低频高强度”两档，按人设选择；
3. 事件层只做二次约束，不承担主配额。

## 决策

- **生产保持 `off`。**
- **不启用 `typed` / `typed-noshape`。**
- **不调 `humanization-v1` 阈值。**
- **下一轮实验必须先改形态层触发条件，再谈事件层配额。**
