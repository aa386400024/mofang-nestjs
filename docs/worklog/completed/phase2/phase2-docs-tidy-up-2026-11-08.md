- 只改 `.md` 文档
- 不改任何 `src/` 代码
- 不改任何测试

### 3.2 企业级标准

- 改之前先核实清楚，不要想当然
- 改完之后再核对一遍，确保前后一致

### 3.3 不要做的事

- 不要改测试
- 不要假设，要逐条核实
