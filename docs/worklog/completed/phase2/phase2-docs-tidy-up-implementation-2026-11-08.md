**核实方法**（不靠肉眼数，用脚本逐行解析登记表）：

```powershell
node -e "const fs=require('fs');const L=fs.readFileSync('docs/worklog/pending/phase2-wp-list-2026-11-03.md','utf8').split(/\r?\n/);
const rows=L.map(l=>l.match(/^\|\s*\*\*WP(\d+)\*\*(\s*✅)?\s*\|/)).filter(Boolean);
console.log('rows',rows.length,'done',rows.filter(r=>r[2]).length,'undone',rows.filter(r=>!r[2]).map(r=>r[1]).join(','));"
```
