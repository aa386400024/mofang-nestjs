## 2. 关键设计决策（与任务单有出入的地方 + 为什么）

### 2.1 决策：「没有 safety / bond 时 prompt 逐字不变」落地成**逐行**口径 —— 偏差

任务单 §4.2 写「如果没有 safety / bond（旧的调用方），就不渲染那一行 → prompt 逐字不变」，但 §6.1 又要求**无条件**加两行（「你可以有一点变化」+「说话方式补非语言」）。这两条**自相矛盾**：那两行一落地，整段 prompt 就不可能「逐字不变」。

所以本单按**行**执行零回归：

| 行 | 依赖什么 | 缺数据时 |
|---|---|---|
| 语气疏离度 | 同盟三维（safety / bond）+ 表达风格阻抗 + 信任 | **不渲染**（缺 safety **且** 缺 bond） |
| 情绪表现 | 情绪标签 + 唤醒 | **不渲染**（情绪是 neutral） |
| 轻量随机 | 无 | 无条件渲染（任务单明确要求） |
| 非语言 | 无 | 无条件渲染（任务单明确要求） |

**为什么"没有 safety / bond"是「两个都没有」，不是「有一个没有」**：任务单 §3.1 的判定草图里，`safety === undefined` / `bond === undefined` 的分支是给"**只带了一个**"准备的（另一个生产者也带另一个）。本单保留了这套写法：**缺的那一维不当成"低"**（那会把没带数据的规格判成疏离），只当成"不知道"。

### 2.2 决策：语气疏离度**条件渲染**在同盟维度上（缺 safety 且缺 bond 就不渲染）—— 偏差

任务单 §4.2 要求"条件渲染"，§6.3 第 3 条要求"没有 safety / bond 时 prompt 逐字不变"。本单照此实现，代价是 **WP50 那条零回归断言必须同步改**（§2.6）。

**这道门在线上永远是开的**：`BdiSnapshot` 的 `safety` / `bond` 是**必填**（`bdi-snapshot.ts`），bootstrap 兜底 `DEFAULT_SAFETY = 0.5` / `DEFAULT_BOND = 0`，`spec-assembler` 无条件把它们传进规格 —— 所以生产路径上每一轮都有同盟三维，语气疏离度**始终渲染**。条件渲染只是给"别的生产者不带这两个可选字段"留的门（内核 `RenderSpec` 里它们是可选的）。

### 2.3 决策：「亲近」那一档**不写"愿意多说几句"** —— 偏差

任务单 §3.1 的 `WARMTH_INSTRUCTION.warm` 原文是「语气放松一点：**愿意多说几句**，也愿意流露一点真实感受」。

「愿意多说几步」是**话量**暗示，而话量已经由上一行（`VERBOSITY_INSTRUCTION`）决定了 —— 两行会**打架**：`trust 0.7 / safety 0.7 / bond 0.5` 但话量阻抗 `verbal 0.8` 时，话量行说「回答要短、要躲闪」，语气行说「愿意多说几句」，模型只能二选一，另一条等于白写。

所以改成「语气放松一点：没那么防备，愿意流露一点真实感受」。同理，`hopeful` 的「语气放松一点，愿意多说几步」改成「语气放松一点，话里带点盼头」。

**原则**：话量归话量、语气归语气 —— 两个维度必须**正交**，否则一条指令会把另一条抵消掉。

### 2.4 决策：情绪表现用**穷尽 Record**，并补齐 `ashamed` / `empty` —— 偏差（两处）

**① 补齐两个标签**：任务单 §3.2 的 switch 只覆盖 8 个标签（`anxious` / `sad` / `angry` / `hurt` / `guarded` / `hopeful` / `relieved` / `neutral`），`ashamed` / `empty` 会落进 `default` 分支 → **静默没有表现方式**（任务单自己的注释列的是 10 个标签，是草图漏了两个）。按用户口径「情绪标签用实际的 10 个」补齐两段文案。

**② 换成穷尽 Record**：`EMOTION_EXPRESSION: Readonly<Record<EmotionLabel, { base: string; high?: string }>>`。

- 与同文件 `STRATEGY_LABEL` / `EMOTION_LABEL` **同一范式**（那两个的注释就写着"用穷尽 Record 而不是查表兜底：新增策略时 TS 会直接报错"）—— 内核新增情绪标签时 TS 直接报错，逼着补中文表现，而不是让新标签静默落到"中性"分支；
- 顺带避开 sonarjs `cognitive-complexity` 上限 25：11 个 case 的 switch 每个 `case` 都要计分，Record 查表则没有这个问题。

`base` = 该标签的常规表现，`high` = 同一标签在**高唤醒**下的另一种表现（焦虑与愤怒在"arousal 高"和"arousal 低"时说话方式明显不同：急 vs 闷）。`neutral` 的 `base` 是空串 —— 中性不给额外指令。

### 2.5 决策：新加的两行都用**自然句**，不用「语气疏离度：」这种标签前缀

本文件既有原则（`VERBOSITY_INSTRUCTION` 的注释）：「给模型的是**可执行的描述**，不是状态标签」。带标签前缀还多一个风险：模型可能把「情绪表现：」当成可以念出来的东西（硬规则第 3 条禁的是"上面那些状态词"）。

所以三行都是自然句：语气疏离度「语气有点疏离：像在应付、像隔着一层……」、情绪表现「这轮你有点焦虑：语速偏快……」、轻量随机「你可以有一点变化：不是每轮都用一样的句式……」。

### 2.6 决策：连带更新 WP50 的零回归断言（2 行 → 3 行）—— 偏差

WP50 在本仓库里立的断言是「同盟三维带来的 prompt 差异 = **恰好**那两行」（`withAlliance` 减去 `- 安全感：` / `- 联结感：` 两行后，必须与缺省版**逐字相同**）。

WP35 的语气疏离度**也由同盟三维驱动**（缺省不渲染），所以同盟维度带来的差异从 2 行变成 3 行。本单把那条断言改成「恰好只多三行」+ 扣掉那三行后仍逐字相同。

**这是口径的自然延伸，不是放宽**：断言强度没降 —— 原来要求"只多了那两行"，现在要求"只多了那三行"，其余部分仍然逐字相同。

### 2.7 决策：测试辅助 `verbosityLine()` 从「按前缀找」改成「按位置取」

原实现：`systemText.split('\n').find((line) => line.startsWith('这轮你'))`。

WP35 的情绪表现那行也是「这轮你有点X：…」，按前缀找就**认错行**了（现在还排在话量行后面，所以碰巧没出错 —— 那是运气，不是结构）。改成取「『这一轮怎么说：』块头的下一行」，认的是模板的**结构不变量**。

### 2.8 决策：手法三的"随机"**只在 prompt 里提示**，不在适配层做随机（照任务单 §3.3）

适配层是**纯函数** —— 同一份规格每次渲染出来一模一样。"随机"做在那一层只有两种做法：把随机结果落库（那是**第二份真相**，而且要处理幂等/清理），或者每次生成新 id（不可复现、不可复盘）。

所以照任务单的结论：只在 prompt 里告诉模型「你可以有一点变化」，让模型自己换花样 —— 不引入任何新状态、不引入任何新的真相源。

### 2.9 决策：手法四作为**独立一行**加在「说话方式」之后，不改既有那一行

任务单 §3.4 说"在'说话方式'那行后面补"。本单照做，且**不动既有那行的原文**（零回归：既有行逐字不动，只往后多一行）。

新行与既有行有部分重复（「停顿」「不要写动作描写」都出现过），这是有意的 —— 既有那行是**通用风格规则**，新行是**表现空间**（叹气 / 犹豫），重复的部分相当于加固。

### 2.10 决策：「说完一两句就停下来」挪到「这一轮怎么说」块的**最后**

原来它紧跟在话量行后面。这一块现在有四行（话量 / 语气 / 情绪 / 变化），把"交还话头"这条**硬行为约束**放在块尾、紧挨下面的「硬规则：」—— 权重最高，不会被上面的表现类指令盖掉。

块内顺序因此是：**话量 → 语气疏离度 → 情绪表现 → 轻量随机 → 说完就停**（用例钉死）。

### 2.11 决策：所有阈值是**工程种子值**，非临床标定

- 疏离度判定：`style >= 0.55 || trust <= 0.3 || safety <= 0.3` → 疏离；`trust >= 0.6 && safety >= 0.6 && bond >= 0.3` → 亲近；其余中性。
  - 阈值与既有 `resolveTurnVerbosity` 的档位边界（0.55 / 0.3）**同一套刻度**，两个维度的口径不打架；
  - **疏离先判**（阻抗优先）：信任/安全感/联结感都高但表达风格阻抗高，仍判疏离 —— 阻抗是这一轮最强的信号；
  - **亲近更保守**（要三个同盟信号同时成立）。
- 高唤醒分界 `0.6`：内核 `resolveEmotionLabel` 用 0.65 分愤怒 / 受伤、0.45 分焦虑 / 愤怒 —— 0.6 落在"明显比平时亢奋"那一侧，又不至于把轻微的紧张算成高唤醒。

⚠️ 全部是**工程种子值，非临床标定** —— 待真实对练校准（任务单 §7 第 3、4 条）。
