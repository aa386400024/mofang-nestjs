## 1. 背景

WP1 落地了 BDI 核心算子（基础会谈事件、三维阻抗、移情、核心信念），但 trust 增量是"一刀切"的——不管来访是安全型依恋还是回避型依恋，同样的共情回应涨的 trust 一样多。

蓝图 §4.5 算子分级里，P1 级"人格调节算子"就是解决这个问题：依恋调节 + 人格特质调节，让不同角色对同一事件的反应差异化。这是"来访从扮演变仿真"的关键一步。

---

## 2. 任务目标

在 engine-core 的算子库里加一层"人格调节算子"，让 trust / 阻抗 / 情绪的增量根据角色的依恋类型和人格特质做差异化调整。

---

## 3. 具体改动

### 3.1 依恋调节（核心，先做这个）

**输入**：角色基线里的依恋类型字段（WP9 / WP10A 的 character_profiles 表已有 `attachmentStyle` 字段）。

**四种依恋类型及其调节规则**（种子值，后续校准）：

| 依恋类型 | trust 增量调节 | 阻抗调节 | 说明 |
|---|---|---|---|
| secure（安全型） | ×1.0（基准） | ×1.0 | 基准线 |
| avoidant（回避型） | ×0.6 | ×1.3 | 信任涨得慢，阻抗更高 |
| anxious（焦虑型） | ×1.2 | ×0.8 | 信任涨得快（渴望亲密），阻抗更低 |
| disorganized（混乱型） | ×0.8 | ×1.2 | 矛盾反应，信任涨但阻抗也高 |

> ⚠️ 系数是工程种子值，不是临床结论——注释里写清楚"待真实对练校准"。

### 3.2 人格特质调节（第二步，先搭架子）

**输入**：角色基线里的人格特质字段（大五人格：开放性/尽责性/外倾性/宜人性/神经质）。

**本期做什么**：
- 先定义端口和接口（`PersonalityModulator` 接口）
- 实现"宜人性高 → 共情回应的 trust 增量 ×1.1"这一条作为示例
- 其他特质留 TODO，不展开（避免 BDI 膨胀）

### 3.3 接入点

算子调用链：`processEvent()` → 基础算子（WP1）→ **人格调节算子（本 WP 新增）** → 输出调整后的 delta。

## 5. 验收标准

1. **单元测试**：同一事件输入（比如"咨询师表达共情"），四种依恋类型的角色，最终 trust delta 各不相同
2. **回归测试**：WP1 既有用例全部绿（基准值 ×1.0 = 不改变现有行为）
3. **边界测试**：依恋类型为空 / 未知值时，回落 ×1.0（不破坏现有角色）
4. **闸门**：eslint 0 error / tsc 0 错 / vitest 全绿
