【核心问题根因分析与改进建议】
================================================================================

1. 【来访者话术极度单一】
   现象: TOP5 话术占了全部来访者消息的 96.0%，平均唯一率只有 25.0%
   根因: 每个角色的"回避/阻抗"行为只有 4-5 个固定句式，LLM 生成时反复复用
   影响: 聊 5-6 轮就开始循环重播，对话快速停滞
   建议: 
   - 每个角色补 15-20 种不同的回避/阻抗表达，要求换角度、换细节、换情绪
   - 在角色 prompt 里加"禁止连续两轮使用相同或相似表达"的约束
   - 加"对话推进度"指标：当来访者连续 3 次回避时，角色自动换个角度切入

2. 【咨询师 nonsense 模式严重退化】
   现象: nonsense 模式完成率只有 65%，停滞率 33%，是所有模式里最差的
   根因: nonsense 模式的 prompt 太弱，AI 只会说"嗯，我在听"，连续 8 条一模一样
   影响: 来访者接不住，对话快速卡死
   定性: 这是预期的反例效果——用来测"咨询师完全不专业时对话会崩成什么样"
   建议: 可以接受，但要确认停滞检测的阈值是否合理，不要误判正常对话

3. 【停滞率 18.7% 偏高】
   现象: 74 场停滞，其中 73 场是 stagnant_heavy_degraded
   根因: 双方都在原地打转——来访者循环话术，咨询师不会破局
   建议: 咨询师 prompt 加"破局策略"：
   - 当来访者连续 2 次回避时，换个角度切入（当下感受/环境细节/身体感受）
   - 不要一直问"你想说什么"，而是给出具体的小切口

4. 【cold 模式反而最稳定】
   现象: 冷淡模式 88% 完成率，只有 6% 停滞
   根因: 冷淡咨询师话少但每句都不一样，来访者反而有更多空间表达
   启示: 不是话越多越好，咨询师的"质量"比"数量"重要

5. 【新角色无数据】
   现象: 4 个新角色 0 场数据
   根因: BullMQ 并发只有 3，前面两批 308 场还没跑完
   建议: 继续等，或者把并发调到 5-6

6. 【脏数据】
   现象: 2 个不在角色池里的角色 slug 各 1 场失败记录
   根因: 测试残留
   建议: 确认后清理掉
