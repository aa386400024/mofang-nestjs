## 1. 两件事都做完了

### 1.1 长会话档案（代码）

**新增 `src/auto-practice/session-profile.ts`**：三档档案 + 纯函数 `resolveSessionProfile` / `parseSessionProfile` / `sessionThresholdsOf` / `targetTurnsBandText`（零 IO / 零 env / 零 NestJS）。

| 档位 | maxTurns | 目标轮次 | 最早自然收尾 | 停滞（字面/无推进） | 危机后置窗 |
|---|---|---|---|---|---|
| `legacy`（缺省） | 15 | — | 5 | 2 / 3 | 4 |
| `standard` | 30 | 20-30 | 20 | 3 / 4 | 4 |
| `long` | 50 | 40-50（目标值 45） | 35 | 4 / 5 | 6 |

**全链路透传**：`POST /sessions` + `POST /batch` 的 `body.sessionProfile` → `AutoPracticeJobData.sessionProfile`
→ `PracticeRunnerService.run` → `decideTurn` 阈值 + `CounselorGenerateOptions.sessionProfile / turnIndex`
→ prompt 长会话纪律块。未传 = legacy。

**`decideTurn` 改为显式接收阈值**（第 4 参 `thresholds`，可选、缺省 legacy），函数体不再读模块常量；
老常量（`DEFAULT_MAX_TURNS` / `STAGNANT_*` / `CRISIS_PRACTICE_TURNS`）改为从 legacy 档案派生，**值一个没变**。

**咨询师 prompt 长会话收尾纪律**（`close-discipline.ts` 动态块，legacy 档 `enabled=false`）：
目标 40-50 轮、**第 35 轮之前不得输出 `[[STATE:END]]`**、不得伪造来访者的发言、不得强行拖轮次、
上面"该收就收"在本场不适用；并写入"当前是第 N 轮"（模型只看得到最近 10 轮历史，不知道自己在第几轮）。

**legacy 逐字不变靠三层护栏**，不是靠人肉核对：
1. 动态纪律块 legacy 关闭 → prompt 字节不变；
2. `counselor-agent.spec.ts` 存**改动前采集的 legacy prompt 逐字快照**（`toBe` 断言，改一个字就红）；
3. `practice-runner.spec.ts` 断言不传档案时第 5 轮即 `natural_close`（老行为）。

**入口纪律**：非法 `sessionProfile` 当场报错（不静默回落）；队列脏档名回落 legacy + 告警；
非 legacy 档下 `maxTurns < 最早收尾轮次` 当场报错（该组合下自然收尾不可达）—— legacy 档不拦，老调用方照旧。

### 1.2 出口④临床标注协议（文档）

`docs/worklog/completed/phase2.5/af091-exit4-clinical-label-protocol-2026-11-18.md`：
六维 schema（trust / safety / bond / verbal / depth / style，含方向中性带 `|delta| ≤ 0.01`）·
标注粒度到轮（1 轮 = 1 次咨询师发言 + 其引发的来访者反应）· 双人盲标（匿名代号、不暴露 gold 锚点）+ 仲裁
（κ 必须在**仲裁前**的原始标注上算）· 一致性门槛（κ ≥ 0.60 / MAE ≤ 0.05 / 每维 signal ≥ 100 轮 /
仲裁率 ≤ 40% / 抽检 ≥ 90%）· 评分公式（缺真值的维不参与 macro 平均、**不许用 0 填充**）·
覆盖率报告与缺口 · 补齐路径 · 8 条禁止事项。

**结论：出口④ = 未通过 / 部分可判。** 与 AF-088 一致，本单把它细化：

- **可判（有限）**：trust / safety / bond 三维在现有真实素材上可建方向基线，但 signal 轮只有
  **49 / 32 / 22**（门槛 100），任何百分数只能标"样本不足的探索值"，**不构成验收**；
- **不可判**：verbal / depth / style **零真值**；触发质量（闸门该跑不该跑）也无逐轮真值；
- `synthetic-supervisor-v1` 的 macroAverage 0.833 / trigger F1 0.64 **不得写成 80% 达标**（`synthetic=true`）。

## 3. 一个必须说明的偏差（任务单数字复现不出来）

任务单写"Ground Truth 的 delta 只覆盖 trust 461 / **bond 9 / safety 2**"，我只读复算的实测值是：

```
cases 12 turns 496 {"trust":461,"bond":22,"resistance":16,"safety":32,"emotionValence":5}
```

- **trust 461 一致**；**bond 是 22 不是 9、safety 是 32 不是 2**；
- 另外还有 **resistance 16** 与 **emotionValence 5**（两者都**不在**六维名单里）；
- 24 轮**完全没有** delta；**trust 的 461 轮里只有 49 轮是非平坦信号**（|delta| > 0.01）；
- **verbal / depth / style = 0**（结论方向不变：三维有真值、三维无真值）。

按 conventions §1.3（任务单与事实不符时按实测写并说明偏差），协议文档写的是**实测值 + 复现命令**。
另外明确写死一条：**案例卡里的 `resistance`（16 轮）是单一聚合维度，不可拆成 verbal/depth/style 冒充**。
