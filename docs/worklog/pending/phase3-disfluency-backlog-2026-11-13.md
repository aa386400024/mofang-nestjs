## 2. 逐条说明（归属与依赖）

### L-2 / L-3 · 指标取值域与跨批次可比性

- **归属**：P1 观测已完（数字入备忘 §2.2）；bounds 补全与校准结论属后续批次。
- **现状**：`density_per100` 实测 1.717809 ~ 3.066747，离任何上界都很远；per_turn 五类实测均 < 0.5。
- **依赖**：真跑批次（样本量与质地都够）。
- **验收**：在真跑批次上给出各指标的建议上下界，且与 `humanization-v1` 判据（若 P2 落地）口径一致。

### L-4 · repetition 位置取舍

- **归属**：P1 量化已完（两批 0.019 ~ 0.031/轮）；取舍需拍板。
- **已知取舍**：「只认子句开头」消除了「今天天气」类跨词边界误计，代价是句中口吃式重复漏计。
- **依赖**：真跑批次上**并算宽松口径**做差。
- **验收**：给出两口径的差值量级，再由主控拍板保留 / 放宽。

### L-5 · filler 词表与位置约束

- **归属**：P1 观测已完；标定依赖真跑批次。
- **已知事实**：旧 6 词 split 口径命中数是新 analyzer 口径的 1.76 ~ 2.30 倍（baseline 26 → 15，pre96 324 → 141）；旧口径最大的两块是「就是」「其实」，而它们绝大多数是句中正常承接，新口径按位置规则不计入。
- **依赖**：真跑批次上分别量「句首 / 标点隔离」与「句中承接」。
- **验收**：给出建议词表增删项与位置约束松紧建议。

### L-6 + P1-N2 · trailoff 阈值与 elongation / trailoff 全零

- **归属**：P1 观测已完；标定依赖真跑批次。
- **已知事实**：两批合计 828 轮，`trailoff_per_turn = 0`、`elongation = 0`。
- **依赖**：先确认生成侧是否产出省略号 / 破折号形态，再谈阈值。
- **验收**：要么给出阈值校准建议，要么明确「本产品线不产出该形态 → 检测器下线」的结论。

### L-7 ~ L-9 · P2 / P3 范围

原样保留蓝图口径，**本单不碰**：P2 做 Prompt 配额 / 三态开关 / 判据文件；P3 做角色实体列 / 迁移 / 透传 / 灰度准出。
