## 〇、定位（先读这段，再读别的）

**Phase2.5 不是功能开发阶段，是验证阶段。**

| 阶段 | 干什么 | 类比 |
|---|---|---|
| Phase2 | 造出引擎（规则算子 / 同盟三维 / 记忆 / 审议层 PoC） | 造出一辆车 |
| **Phase2.5** | **把车开上路试一圈——小范围验证质量，确认没问题再正式上路** | **试车场** |
| Phase3 | 正式上路商业化（全量切 + 收费） | 正式运营 |

**一句话：Phase2.5 的目标不是"做新功能"，而是"用真实数据验证引擎质量达标，决定要不要全量切"。**

---

## 一、为什么需要 Phase2.5

Phase2 做完的是**引擎能力建设**，但有几个关键问题还没验证：

1. **合规问题没解决** —— 审议 prompt 传心理原文，数据出境第三方，不合规不能上线
2. **可复现问题没解决** —— 考核场景要公平，LLM 审议是概率性的，做不到逐字复现
3. **成本问题没验证** —— 每轮都跑审议，成本到底高不高？
4. **质量问题没验证** —— LLM 审议的建议到底准不准？跟规则算子比，好多少？

直接跳 Phase3（商业化）太冒险——你不知道 LLM 审议效果好不好、成本扛不扛得住、合规有没有坑。

所以中间需要一个 **Phase2.5 = 灰度验证期**，目标是：
- 解决切灰度前必须解决的合规 / 可复现问题
- 用自动化方式跑几千场对话，验证审议质量
- 确认达标后，再进 Phase3

## 二、出口条件（做完的标志）

| # | 出口条件 | 可判定标准 |
|---|---|---|
| ① **合规过线** | 审议不传心理原文，只传结构化数据；高风险轮次永远走本地规则 | 合规口径过关，法务/隐私无异议 |
| ② **考核公平** | 考核场景永远走纯规则模式，LLM 审议只用于非考核场景 | 同一场考核两次跑结果一致 |
| ③ **成本可控** | 触发式闸门——只有状态变化大才跑审议，平静时不跑 | 单场（50 分钟）审议成本 ≤ 1 元 |
| ④ **质量达标** | 审议建议准确率 ≥ 80%（用督导解析当 ground truth 自动评测） | 自动评测报告达标 |
| ⑤ **数据积累** | 1000+ 场自动对练数据（用模拟咨询师 AI 自动跑） | 数据集齐备 |

> ⚠️ **为什么是 1000 场不是 100 场**：咱们没有真实内测用户，用 AI 模拟咨询师自动跑，一天就能跑几百场——1000 场一周就能跑完，而且可复现、可控。

## 五、关键设计决策（已确认）

### 5.1 合规方案：审议不传原文，只传结构化数据

**为什么这是最优解：**
- 审议的本质是"评估 delta 合不合理"，不是"理解对话内容"——结构化数据足够了
- 不传原文 = 心理数据不出境 = 合规问题从根上解决
- 还顺便解决了成本问题——上下文短了，token 成本直接降一半

**传什么 vs 不传什么：**

| 传什么 | 不传什么 |
|---|---|
| 结构化事件分类（比如"咨询师表达了共情"） | 咨询师说的具体内容 |
| 状态变化前后的对比（trust 0.5 → 0.58） | AI 来访者说的具体内容 |
| 角色设定简述（依恋风格、人格基线） | 对话原文 |
| 风险等级（低/中/高） | —— |

### 5.2 可复现方案：考核场景永远纯规则

**为什么不是"把 LLM 变得可复现"：**
- LLM 是概率性的，做不到绝对逐字复现
- 考核要的是"公平"——所有考生面对同一个 AI 来访者，同一条状态变化路径
- 所以考核场景**从根上就不该用 LLM 审议**

**做法：**
- 考核场景 → 永远走纯规则模式（不切 LLM 审议）
- 自由练习 / 全真执业 → 可配置切 LLM 审议
- 模型 / prompt 版本号记录到 trace 里（为了效果对比和问题追溯，不是为了逐字复现）

### 5.3 成本方案：触发式闸门，不是频率闸门

**为什么不是每 N 轮跑一次：**
- 审议的价值是"规则算子算不准的地方，LLM 来补"
- 平静的日常对话，规则算子够准，没必要跑审议
- 状态变化大的时候，规则算子算不准，才需要 LLM 来补

**做法：**

| 触发条件 | 跑不跑审议 |
|---|---|
| 状态变化幅度大（某维度变化 > 阈值） | ✅ 跑审议（规则算不准，LLM 来补） |
| 风险等级高（危机 / 自杀倾向） | ❌ 不跑（永远走本地规则，合规红线） |
| 常规平静对话 | ❌ 不跑（规则够了，省成本） |

**预期效果：** 总跑数大概是每 10-15 轮跑一次——成本降 90%，但效果没降。

### 5.4 验证方案：AI 模拟咨询师自动跑

**为什么不用真实内测用户：**
- 没有真实用户
- 真实用户跑太慢（2 周 100 场）
- 真实用户不可复现（每个人打法不一样）

**做法：**
1. 用一万份心理咨询个案逐字稿（附督导解析），训练一个"模拟咨询师"AI
2. 让模拟咨询师跟咱们的 AI 来访者自动对练，跑几千场
3. 用督导解析里的判断当 ground truth，自动评测审议效果
4. 根据评测结果调参数，调到准确率 ≥80%

**额外价值：** 这个"模拟咨询师"AI 以后还能当产品功能——用户没人对练的时候，可以跟模拟咨询师 AI 打配合。
