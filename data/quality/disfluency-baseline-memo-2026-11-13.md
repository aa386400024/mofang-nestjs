## 0. 一句话结论

两个离线批次都已跑通 D7 口径（脚本 exit 0），八指标与六类计数**可离线复算、跨批次同口径**；但两批有效样本量差异极大（4 场 vs 70 场），因此本备忘只作**口径锚点**，**不作临床标定结论**。

## 1. 口径说明

- 主口径 = **批次合计口径**（合计事件 ÷ 合计纳入轮数），与 P0 快照 `text.disfluency.*` 同源。
- **跨场均值**（先算每场比率再平均）另列作参考，两者**不混用**。
- 纳入范围 = `degradedTurns === 0` 的有效场次；降级场次不计入基线均值。
- 种子区间（蓝图 §5.2.4）只作并列对照，**不出 PASS / FAIL，不接门禁**。

### 2.5 批次有效性局限（必读）

1. **baseline-20261109 只有 4 场可用**：500 场里 496 场有渲染降级（DB runner 落库口径），有效场次合计仅 52 轮 —— 样本量不足以支撑任何分布结论，该批数字**只能当作口径可跑通的锚点**。
2. **baseline 是早期 debug 归档**：README §3.1 记录该批兜底句占比 91.8%、大量场次 `total_tokens = 0`，其不流利分布偏低 / 失真属预期；**不得**把该批区间当临床标定结论。
3. **两批强度差异的方向不选边**：baseline 的 events_per_turn / pause_per_turn 明显高于 pre96，repetition_per_turn 明显低于 pre96。既可能是「早期兜底句更啰嗦」的真实差异，也可能是 4 场样本的偶然波动 —— 拿到真跑批次样本前不下结论。
4. **trailoff 与 elongation 两批全为 0**：两个检测器依赖的省略号 / 破折号标记在访客台词里一次都没出现（两批合计 828 轮，命中 0 次）。要么这批访客确实从不写省略号，要么生成侧从不产出该形态 —— **当前数据无法区分**。
5. **跨批次可比的是「同一套口径下的相对关系」**，不是绝对值；绝对值只在同批次同口径内可复算。

## 3. 建议调参（建议项，不落到任何代码或判据）

1. **filler 词表与位置约束（L-5）**：先在真跑批次上量「句首 / 标点隔离」与「句中承接」两个口径的差，再决定 `FILLER_WORDS` 是否增词、位置约束是否放宽。当前证据（计入率 43.5% ~ 57.7%）来自两个不同质地的批次，不足以定标。
2. **pause 类目边界（L-3 / L-6 相关）**：pause 是两批最大的事件类（baseline 23/51、pre96 161/468）。建议先确认访客文本里真实存在的停顿形态（逗号 / 省略号 / 重复标点）分布，再决定是否收紧识别，避免把「陈述停顿」与「不流利停顿」混进同一类。
3. **trailoff / elongation 全零（L-6）**：建议在真跑批次上单独确认访客侧是否会产出省略号 / 破折号形态；若确实不产出，这两类检测器在本产品线上的**实际有效性为零**，应考虑下轮改为「先观察生成侧形态，再决定是否保留检测器」。
4. **种子区间校准（L-2 / L-3）**：三条种子区间里 `repair_per_turn ≤ 0.25` 在两批都落在区间内、且 baseline 已达上界的 92.3%，是三格中最接近边界的一条；建议 P2 接判据前先在真跑批次上重算这三个数，再谈区间取值。
5. **repetition 位置取舍（L-4）**：repetition 在两批都极低（0.019 ~ 0.031/轮），与「只认子句开头」的保守口径一致；建议在真跑批次上对同一批台词**并算宽松口径**做差，量化这条取舍压掉了多少，再决定是否放宽。
6. **density_per100 取值域（L-2 / L-3）**：两批实测 1.72 ~ 3.07，远未触到任何上界，暂不具备定上界的依据；建议等真跑批次。
